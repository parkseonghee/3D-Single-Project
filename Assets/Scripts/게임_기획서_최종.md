# 게임 기획서 (최종)

> 장르: 3D 뱀서라이크 + 부대 편성 · 성장 | 엔진: Unity | 에셋: Toony Tiny RTS Set | 1인 개발 · 포트폴리오용

> **개발 기준 갱신 (2026-09-10):** 성장·경제 규칙은 아래 기준으로 구현한다. 수치는 플레이 검증 전의 임시값이며, 우선 게임 전체 기능을 완성한 뒤 최종 밸런스를 조정한다. 카드의 분류·선택 구조는 이번 수정 대상에서 제외하고 기존 기획을 유지한다. 참고 HTML과 다른 성장 규칙은 이 문서를 우선한다.

## 1. 한 줄 설명

*군인을 키우고 편성해 뱀서라이크 전장에 투입하는 3D 군대 서바이버. 마을과 전장을 오가며 100일을 버텨라 — 어떤 부대를 데려가느냐가 곧 빌드다.*

## 2. 이 게임의 핵심 재미

근본적인 재미는 “내 부대를 키우고 → 어떻게 조합해 내보낼지 궁리하고 → 전장에서 쓸어담는” 사이클의 반복이다.

- **편성이 곧 빌드:** 전장 밖에서 키운 군인을 어떻게 조합하느냐(병사 5 + 궁수 2 vs 궁수 다수)에 따라 매 판 플레이가 완전히 달라진다.
- **쓸어담는 쾌감:** 몰려오는 적을, 레벨업으로 눈덩이처럼 강해진 부대로 정리하는 뱀서라이크 특유의 도파민.
- **내 유닛을 키우는 애착:** 기본공격으로 시작해 레벨업으로 스킬을 얻고 강화해 나가며, 내 손으로 부대를 키우는 육성 재미.
- **지금의 힘 vs 미래의 성장:** 카드가 스킬 강화(현재 전투)와 자원형(미래 성장) 사이 선택을 강요한다.
- **두 레이어의 리듬:** 스릴 있는 전장(런)과 계획하는 기지(메타)를 오가며 다음 편성을 궁리하는 리듬.

## 3. 게임 플레이 방식

- **아이소메트릭 뷰:** 3D 공간을 사선 위에서 내려다보는 직교 카메라를 기본으로 사용한다. 카메라 각도·줌·추적 속도는 설정 데이터로 관리하며, 이동 입력은 카메라의 지면 기준 방향에 맞춰 변환한다.
- **지휘관 직접 조작:** 플레이어는 지휘관 1명만 직접 이동 조작한다. 뱀서 원류의 즉각적인 손맛을 담당하는 유일한 수동 조작.
- **부대 자동 전투 + 수동 이동:** 편성 유닛은 지휘관을 따라다니며 자동 전투(포메이션). 필요 시 RTS식으로 특정 유닛을 마우스 드래그해 이동시킬 수 있다.
- **스킬은 전부 자동 발동:** 모든 스킬은 쿨다운 또는 패시브 오라로 자동 작동한다. 플레이어는 위치 선정과 편성으로 전투를 지휘한다.
- **기본공격 → 스킬 → 강화:** 각 클래스는 기본공격으로 시작해, 레벨업 시 새 스킬을 얻거나 보유 스킬을 +강화하며 강해진다.
- **생존과 정리:** 점점 거세지는 적의 물결을 생존하며 스테이지 목표를 달성한다.

## 4. 편성 · 빌드 시스템

### 4.1 유닛 역할

| 유닛 역할 | 예시 | 뱀서에서의 기능 |
|---|---|---|
| 근접 | 병사 | 지휘관 주변 근접 딜 / 몸빵 |
| 원거리 | 궁수 | 자동 조준 원거리 오토어택 |
| 탱커 | 방패병 | 전방 흡수, 지휘관 보호 |
| 범위/특수 | 마법사 | 광역 폭발 · 상태이상 |
| 기동 | 기병 | 돌진 · 라인 정리 |

- **편성 제한:** 하우징/코스트 방식으로 데려갈 인원을 제한한다(예: 병사 5 + 궁수 2). 무엇을 넣고 뺄지가 핵심 선택.

### 4.2 스킬 성장 구조

- **기본공격으로 시작:** 각 클래스는 기본공격 하나로 시작한다(예: 병사 = 검 베기).
- **레벨업 → 스킬 획득:** 클래스 레벨업 시 새 스킬을 드래프트로 얻는다(예: 회전검).
- **클래스 공통 성장:** 같은 클래스의 편성 유닛은 전투 레벨·경험치·보유 스킬·강화 단계를 공유한다. 병사 클래스의 회전검을 강화하면 편성된 병사 전원에게 적용한다. 개별 병사의 체력·위치·공격 및 스킬 쿨다운은 각각 관리한다.
- **지원 효과 중첩:** 같은 이름의 오라·능력치 버프는 가장 강한 효과 하나만 적용한다. 같은 이름의 실드는 합산하지 않고, 기존 잔여량과 새 실드량 중 큰 값으로 갱신하며 지속시간을 갱신한다. 공격과 피해 판정은 각 유닛이 개별 수행한다.
- **+강화 누적:** 이미 가진 스킬·기본공격이 다시 나오면 강화가 누적된다(회전검 +1, +2 … = 자루·범위 증가).
- **확장 구조:** 핵심 액티브 + 모디파이어(+N 강화) 조합으로 클래스당 실질 10종 이상이 자연스럽게 나온다.

### 4.4 스킬 구현 원형 (4가지)

- **오라 존:** 내 주위 원형 트리거 안의 적/아군에게 지속 효과 (가시·공격력 오라, 불장판).
- **궤도 히트박스:** 회전하는 자식 트랜스폼 + 트리거 (회전검).
- **발사체:** 스폰 → 전진 → 히트 (검기, 화살 계열, 메테오).
- **AoE / 장판:** 특정 위치에 원형 데미지·지속 존 (폭발, 착탄, 돌진 자리 불길).

### 4.5 경험치 병 & 레벨업

- **획득:** 런 중 적을 처치하면 경험치 병이 드랍되고, 지휘관이 접촉해 수집한다(전장 안에서만 유효, 클리어 시 정리).
- **사용:** 모은 경험치 병을 원하는 **클래스에 투자**해 그 클래스를 레벨업시킨다. 클래스가 레벨업하면 해당 클래스 전용 스킬 드래프트 3장이 등장한다(4.3 풀).
- **투자 대상:** 현재 출전한 클래스 중 선택한다. 개별 병사별로 경험치 병을 배분하지 않는다. 병력 수가 바뀌어도 해당 전장의 클래스 성장 상태는 유지한다.
- **임시 경험치 기준:** 병 1개 = 100 EXP, 현재 클래스 레벨 L에서 다음 레벨까지 필요한 경험치는 `100 × (L + 2)`로 시작한다. 클래스 인원수에 따른 비용 가산은 우선 적용하지 않는다. 초과 경험치는 유지하고 연속 레벨업 선택은 순서대로 처리한다.
- **성장 빈도 목표:** 첫 전장에서 경험치 병으로 얻는 클래스 성장 선택은 모든 클래스 합계 6~8회를 목표로 한다. 지휘관·특수 적 카드와 시작 무료 성장 선택은 이 횟수에 포함하지 않는다. 목표에 맞춰 경험치 병 공급량을 조정하되, 최종 조정은 게임 완성 후 진행한다.
- **설계 의도:** 병을 플레이어가 직접 배분하므로, 특정 유닛이 경험치를 독식하는 문제가 없다. "어느 클래스를 먼저 키울지"가 런 도중의 선택이 된다.
- **지휘관 레벨은 별도:** 지휘관은 전투 기여로 자체 경험치를 쌓고, 레벨업 시 자원형 카드(메타 성장) 3장을 받는다(6번 참조).

## 5. 자원 · 경제

재화는 층을 나눠 서로 겹치지 않게 한다. 벼 = 만들기/뽑기, 골드 = 키우기, 특수 자원 = 깊은 성장.

| 재화 | 획득 | 용도 | 성격 |
|---|---|---|---|
| 벼 (메타) | 전장 밖에서 채취 | 병사 고용 + 건물 제작 | 자주 쓰는 기본 재화 |
| 골드 (회차) | 스테이지 안에서 획득 | 병사 · 건물 강화 | 전장 간 유지되는 강화 재화 |
| 특수 자원 | 보스 처치로만 획득 | 캐릭터 영구 강화 (예: 시작 무료 성장 선택, 시작 자원 보너스, 스킬 슬롯 해금) | 회차 간 유지되는 성장 재화 |
| 경험치 병 | 런 중 적 처치 | 클래스 레벨업 | 전장 안에서만 유효 |

### 5.1 Day별 벼 채취

- **기본 한도:** 시작 논 1개를 포함해 하루 총 100개를 25개씩 4회 채취한다. ‘100개’는 1회 채취량이 아닌 하루 기본 총량이다.
- **갱신:** Day 1 시작과 전장 클리어 후 다음 Day 진입 시 한도·횟수를 설정한다. 미사용 횟수와 미채취량은 이월하지 않으며, 이미 보유한 벼는 유지한다.
- **당일 한도 고정:** Day 진입 시 논 상태를 기준으로 총량을 확정한다. 같은 Day의 건설·강화·철거, 화면 재진입, 저장·불러오기로 한도를 다시 계산하거나 횟수를 회복하지 않는다. 당일 총량·남은 횟수·남은 채취량을 저장한다.
- **논의 효과:** 추가 논과 논 강화는 다음 Day부터 하루 총 채취량만 늘린다. 채취 횟수는 4회로 고정하고, 논에서 별도로 지급하는 클리어 자동 수확은 두지 않는다. 전장·카드 보상은 채취 한도와 별개이며 카드 규칙은 기존 기획을 유지한다.
- **표시 예시:** `벼 25개 채취 · 4회 남음 · 오늘 남은 수확량 100`. 총량을 4등분하되 나눗셈 잔여분은 마지막 채취에서 지급한다.

### 5.2 초기 경제 임시값

| 항목 | 초기 구현 기준 |
|---|---|
| 새 회차 시작 | 벼 320, 골드 0, 병사 3명, 논·병영·막사 각 1개 |
| 시작 편성 상한 | 5명, 우선 모든 클래스 1명당 편성 1칸 사용 |
| 병사 고용 | 1명당 벼 60 |
| 첫 추가 논 | 벼 120, 다음 Day부터 하루 총 채취량 +40 |
| 추가 논 반복 건설 | n번째 추가 논 비용 `반올림(120 × 1.5^(n-1))`, 각 논의 기본 증가량 +40 |
| 논 강화 | 각 논 Lv.1에서 시작, 다음 레벨 비용 `반올림(80 × 1.5^(현재 레벨-1))` 골드, 레벨당 하루 총량 +20 |

- 시작 논의 기본 생산은 하루 100개에 이미 포함되어 있으며 중복 합산하지 않는다. 시작 논의 강화 증가분은 정상 적용한다.
- 첫 추가 논은 채취를 모두 할 때 3일의 생산으로 건설비를 회수하는 기준이다. 당일 병력 확보와 이후 경제 성장 사이의 선택을 만든다.
- 병사·건물 강화 비용과 전장 보상은 데이터로 분리한다. 초기 수치는 임시값으로 두고, 하루 수입 대비 고용·강화 가능 횟수를 기준으로 최종 조정한다.

## 6. 카드 드래프트

카드는 세 가지 출처로 나뉘며, 역할을 분리해 중복을 없앴다.

- **클래스 레벨업 → 스킬 드래프트:** 새 스킬 획득 또는 보유 스킬 +강화 3장 중 택1(4.3 풀에서).
- **지휘관 레벨업 → 자원형 카드:** 미래(메타 성장)를 위한 자원을 얻는 카드 3장 중 택1.
- **특수 적 처치 → 즉시형 카드:** 현재 전투를 뒤집는 강력한 즉시 효과(예: 화면 정리 폭발, 잠깐 전체 무적, 경험치 병 다발).

## 7. 코어 루프

하루(Day)마다 **마을(메타) → 전장(런) → 마을** 사이클을 돈다.

### 7.1 마을 · 메타 (전장 밖, 시간 소모 없음)

- 벼 채취 (5.1의 Day별 한도 안에서 자원 획득)
- 병사 고용 · 건물 제작 (벼 소모)
- 병사 · 건물 강화 (골드 소모, 대기 없이 즉시 완료)
- 그날 스테이지용 부대 편성 (인원 제한 내 조합)

### 7.2 런 (전장 안 · 뱀서, 하루 소모)

- 편성된 부대로 스테이지 진입
- 몰려오는 적 자동 전투 + 지휘관 이동으로 **제한 시간 생존**, 골드·경험치 병 수집
- 클래스 레벨업 → 스킬 강화 카드 3장 택1
- 지휘관 레벨업 → 자원형 카드 3장 택1
- 특수 적 처치 → 즉시형 카드
- 제한 시간을 버티면(보스 Day는 보스 격파) 클리어 → **마을로 귀환** + 자원·해금 획득 (보스 시 특수 자원)
- 클리어 실패 시 병력이 쳐들어와 패배

## 8. 진행 · 난이도 구조

게임은 **Day 1 ~ Day 100**으로 진행되며, 하루가 한 판 사이클이다. 100일을 버텨내면 클리어(엔딩).

- **Day = 스테이지:** Day 1 = 1스테이지, Day 2 = 2스테이지 … 로 하루마다 스테이지가 하나씩 진행된다. Day가 오를수록 강해진다.
- **하루의 흐름:** 마을(메타)에서 편성·건설·강화 준비 → 전장(스테이지) 진입 → **생존형(제한 시간 버티기)** 클리어 → 마을로 귀환 → 다음 Day. 스테이지가 넘어가는 게 아니라 매번 마을로 돌아온다.
- **시간 소모:** 하루(Day)를 소모하는 것은 **전장(스테이지) 클리어**뿐. 마을 정비는 시간을 소모하지 않는다.
- **보스:** **10스테이지(Day)마다 보스전**(Day 10 · 20 · 30 … 100). 나머지 날은 일반 생존 스테이지.
- **패배 조건:** 해당 Day의 스테이지를 클리어하지 못하면(제한 시간 안에 지휘관 사망), 병력이 마을로 쳐들어와 패배(게임 오버).
- **난이도 상승:** Day가 올라갈수록 난이도는 높아지되, 적 밀도·체력·공격력·특수 적 빈도·생존 시간을 독립적으로 설정한다. 모든 항목을 매일 동시에 올리는 고정 공식은 사용하지 않는다.
- **성장 누적:** Day 1~100을 하나의 ‘회차’, 하루의 전투를 하나의 ‘전장’으로 구분한다. 건물·해금 등 회차 성장은 100일 동안 누적되고 전장 한정 성장은 매 전장 종료 시 정리한다.

### 8.1 성장 유지 범위

| 범위 | 대상 | 초기화 기준 |
|---|---|---|
| 전장 성장 | 경험치 병, 클래스·지휘관 전투 레벨과 경험치, 스킬·강화, 임시 버프 | 전장 종료 시 초기화 |
| 회차 성장 | 벼·골드, 고용 병력, 건물·강화, 클래스 해금, 병사 강화 | 다음 Day에는 유지, 새 회차 시작 시 초기화 |
| 영구 성장 | 특수 자원 잔액, 제단 강화, 최고 기록 | 게임 오버·엔딩 후 새 회차에도 유지 |

- 출전 유닛의 전장 내 사망은 고용 병력의 영구 손실로 처리하지 않는다. 클리어 후 다음 출전에는 회차 강화가 적용된 최대 체력으로 시작한다. 지휘관 사망은 기존 기획대로 회차 종료다.
- 새 회차는 5.2의 시작 상태에 영구 강화 효과를 적용한다. 제단 건물 자체는 초기화되지만 이미 구매한 영구 효과는 제단 재건 전에도 적용된다. 추가 구매에는 제단이 필요하다.

### 8.2 개발 중 난이도 기준

| 구간 | 구현·진행 목표 |
|---|---|
| Day 1 | 시작 병력으로 클리어 가능, 병력 추가와 경제 투자 선택 |
| Day 2~3 | 원거리 또는 탱커를 확보해 혼합 편성 경험 |
| Day 4~6 | 새 클래스 해금과 기존 부대 강화 사이 선택 |
| Day 7~9 | 첫 보스 대비를 위한 편성·강화 |
| Day 10 | 영구 강화 없이도 회차 성장과 전장 선택으로 격파 가능 |
| Day 11~100 | 10일 단위 구간 데이터로 확장, 10일마다 보스 유지 |

- 일반 전장 시간은 우선 90~180초 범위로 설정한다. 개발 중에는 전체 회차를 진행할 수 있는 임시 난이도를 제공하고, 정밀한 승률 조정 때문에 기능 완성을 지연하지 않는다.
- 난이도의 기준은 영구 강화가 없는 새 회차다. 후반 진행에 반복 회차를 통한 영구 강화 획득을 필수 조건으로 두지 않는다.
- 적 능력치·출현 주기·보상·생존 시간·강화 비용은 구간별 데이터로 관리한다. 참고 HTML의 Day 배율과 강화 비용 공식을 최종 밸런스로 고정하지 않는다.

## 9. 건설 시스템

건물은 기지(전장 밖)에서 **벼로 즉시 제작**하고(대기 시간 없음), **골드로 강화**한다. 건물은 두 축으로 나뉜다 — 해금·확장(클래스·편성 상한)과 경제·강화(자원·전군 강화).

| 건물 | 제작(벼) | 기능 | 강화(골드) 효과 |
|---|---|---|---|
| 논 | 5.2 참조 | 다음 Day부터 일일 채취 총량↑ | 다음 Day부터 총량 추가↑, 횟수는 4회 고정 |
| 막사(하우징) | 중간 | 편성 인원 상한↑ (데려갈 병력 수) | 상한 추가↑ |
| 병영 | 낮음 | 병사 고용·해금 | 병사 기본 스탯↑ |
| 방패 훈련소 | 중간 | 방패병 해금 | 방패병 스탯↑ |
| 사격장 | 중간 | 궁수 해금 | 궁수 스탯↑ |
| 마법탑 | 높음 | 마법사 해금 | 마법사 스탯↑ |
| 마구간 | 높음 | 기병 해금 | 기병 스탯↑ |
| 대장간 | 중간 | 전군 강화 거점 | 전 부대 공격력·체력↑ |

- **제단(특수 건물):** 벼로 제작하되, 기능은 **특수 자원**(보스 처치 재화)을 소모해 캐릭터를 영구 강화한다(시작 무료 성장 선택, 시작 자원 보너스, 스킬 슬롯 해금 등).
- 제작 비용·수치는 튜닝 예정('제작(벼)'은 상대적 감각).
- 건물·클래스 해금은 다음 Day에도 유지하며, 새 회차 시작 시 초기화한다(8.1 참조).

### 9.1 제단 영구 강화 임시 기준

| 강화 | 효과 | 상한 | 단계 구매 비용 |
|---|---|---|---|
| 지휘관 단련 | 기본 최대 체력의 +5%씩 가산 | 5단계, 최대 +25% | 특수 자원 1 |
| 전술 교본 | 전장 시작 시 출전 클래스 하나를 선택해 무료 레벨업 및 해당 클래스 스킬 선택 1회 | 1단계 | 특수 자원 2 |
| 보급 창고 | 새 회차 시작 벼 +40씩 가산 | 3단계, 최대 +120 | 특수 자원 2 |
| 스킬 슬롯 확장 | 클래스별 기본공격 외 보유 스킬 상한 4개 → 5개 | 1단계 | 특수 자원 3 |

- 지휘관 기본 최대 체력은 임시 280으로 시작하며, 단련 최대 적용 시 350이다. 전장 내 성장 효과는 이후 별도로 적용한다.
- 전술 교본은 레벨 숫자만 올리지 않는다. 정상 레벨업과 동일한 효과와 스킬 드래프트를 지급하며 경험치 병은 소모하지 않는다. 시작 선택 완료 후 전장 시간이 흐른다.
- 영구 강화는 선택의 폭과 초반 안정성을 보조한다. 반복 플레이를 통한 큰 능력치 누적이 공략의 필수 조건이 되지 않도록 한다.

## 10. 게임 완성 후 밸런스 조정

- **현재 우선순위:** 위 규칙과 임시값으로 마을·전장·성장·100일 진행을 구현한다. 진행 불가, 자원 무한 획득 등 기능 결함은 개발 중 수정하되 세밀한 수치 조정은 전체 기능 완성 후 진행한다.
- **경제 확인:** Day별 벼·골드 수입과 지출, 논 투자 회수 기간, 실제 고용·강화 횟수, 남는 자원을 측정한다.
- **전투 확인:** 클래스별 피해·지원 기여, 같은 편성 한도에서 단일 클래스와 혼합 편성의 성능, 경험치 투자 편중, 성장 선택 횟수, 보스 소요 시간과 사망 원인을 확인한다.
- **성장 확인:** 영구 강화가 없는 상태와 상한 상태를 비교하고, 초기 10일과 후반 구간의 진행 가능성을 각각 확인한다.
- **조정 순서:** 전투 기본 성능 → 경험치 공급과 성장 속도 → 일일 경제와 강화 비용 → Day별 난이도 → 영구 성장 순서로 조정한다. 카드 상세 밸런스는 이번 변경에서 보류하며 완성 후 별도로 검토한다.

## 11. 포트폴리오 개발 원칙

### 11.1 하드코딩 금지 · 데이터 중심 설계

- 유닛 능력치, 고용·강화 비용, 경험치 요구량, 스킬 효과·성장량, Day별 웨이브·보상, 건물 생산량, 카메라 설정을 실행 코드에 고정하지 않는다. 이 문서의 임시 수치도 설정 데이터로 옮겨 사용한다.
- 공통 정의 데이터는 ScriptableObject 등 편집 가능한 에셋으로 관리하고, 씬·프리팹의 연결은 직렬화된 참조로 구성한다. 유닛·스킬 이름이나 씬 오브젝트 이름을 문자열로 비교해 동작을 분기하지 않는다.
- 입력은 Input Actions로 관리한다. 에셋 경로·입력 키·레이어·애니메이션 연결을 여러 코드에 흩어 넣지 않는다. 필요한 식별자는 한곳에서 관리하고 설정 누락을 검증한다.
- 정의 데이터와 실행 중 상태를 분리한다. 공유 ScriptableObject에 현재 체력·경험치·쿨다운·보유 재화 등을 기록하지 않으며, 전장·회차·영구 상태는 각각 별도로 관리한다.
- 데이터에 따라 동작하는 공통 로직을 구현하되, 기능에 필요한 범위에서 책임을 나눈다. 단순 기능에 불필요한 추상화나 범용 프레임워크를 도입하지 않는다.

### 11.2 코드 작성 후 학습용 설명

- 코드를 작성하거나 수정할 때마다 사용자에게 한국어로 설명한다.
- 설명에는 해결하려는 문제, 각 클래스의 책임, 실행 순서와 데이터 흐름, 주요 메서드의 동작, 설계 이유를 포함한다.
- Inspector에서 연결할 항목, 설정 에셋에서 조절할 값, 실행·검증 방법과 확인 결과를 함께 안내한다.
- 설명은 실제 작성한 파일과 코드에 연결한다. 처음 나오는 Unity·C# 개념은 간단히 풀어 설명하고 변경 규모에 맞춰 상세도를 조절한다.

### 11.3 아이소메트릭 에셋 활용 기준

- 확인된 에셋 경로: `Assets/ToonyTinyPeople/TT_RTS/TT_RTS_Standard`.
- 캐릭터 프리팹에 지휘관(`TT_Commander`), 병사(`TT_Swordman`), 궁수(`TT_Archer`), 마법사(`TT_Mage`), 기병(`TT_Light_Cavalry`, `TT_Heavy_Cavalry`) 등이 있다. 방패병의 모델은 보병·팔라딘 후보를 실제 외형 확인 후 선택한다.
