# 도서관과 출전 유물

모험 모드에서 도서관을 건설하면 전투 시작 버튼을 누른 뒤 전투 카메라와 HUD로 전환하고 유물 후보 3장을 화면 중앙에 띄운다. 선택하는 동안 전투 시간이 멈추며, 하나를 고르면 시작 보상이 적용되고 전투가 진행된다. 도서관이 없으면 기존처럼 바로 진행한다. 서바이벌 모드에는 도서관을 적용하지 않는다.

## 연결 구조

- `Assets/BuildingData/Library.asset`: ToonyTinyPeople `Library.FBX` 모델, 벼 건설비·골드 강화비, 아이콘과 배치 크기. `VillageScene`의 건설 목록·건물 설명·저장 대상에 등록되어 있다.
- `RelicDraftController`: `PlayScene`에 미리 배치한 선택 창을 연다. 비활성화된 마을에서도 도서관 건설 상태를 조회하고, 서로 다른 유물 후보 3장을 섞어 보여준다. 선택하는 동안 시간을 멈추고, 카드를 고르면 효과를 적용한 뒤 시간을 복원한다.
- `RelicDefinition`: 각 유물의 이름, 설명, 아이콘, 시작 경험치 병·지휘관 보호막·병사 보호막, 도서관 강화당 증가량, 보호막 지속 시간을 보관하는 ScriptableObject다. 실행 코드에 밸런스 수치를 고정하지 않는다.
- `RunController`: 기존 전투 시작 호출에서 전투 카메라·HUD와 병력 상태를 먼저 초기화하고, 그 직후 도서관 유물 창을 연다.
- `CardMotion`: 기존 DOTween 카드 등장·호버·선택 연출을 재사용한다.

## 기본 유물

| 데이터 에셋 | 효과 | 도서관 강화당 추가 효과 |
|---|---|---|
| `FieldManual.asset` | 경험치 병 3개 | 병 +1개 |
| `RoyalCrest.asset` | 지휘관 보호막 90 | 보호막 +20 |
| `GuardOath.asset` | 모든 병사 보호막 45 | 보호막 +10 |
| `ExpeditionPlan.asset` | 병 1개, 지휘관 보호막 55 | 병 +1개, 보호막 +20 |
| `EscortManual.asset` | 병 1개, 모든 병사 보호막 25 | 병 +1개, 보호막 +10 |

보호막 지속 시간은 각 유물 에셋에서 조정하며 초기값은 180초다. 보호막은 시작 시점의 편성 병사에게 적용된다. 도서관을 여러 채 지은 경우 강화 단계가 가장 높은 도서관을 기준으로 계산한다.

## 에디터에서 조정

1. `Library.asset`에서 건설비, 강화비, 반복 건설 비용 배율과 모델 배치를 조정한다.
2. `Assets/RelicData`의 에셋에서 유물별 보상과 강화 증가량을 조정한다. 새 유물을 추가하면 `PlayScene > Recruitment System > Relic Draft Controller > Relics`에 등록한다.
3. `PlayScene > Recruitment UI > Library Relic Draft`에서 카드 레이아웃을 조정하고, `Relic Draft Controller > Motion Config`에서 카드 동작을 조정한다.

마을에서 도서관을 건설하고 병사를 한 명 이상 편성한 뒤 모험 모드 전투를 시작하면 전투 화면 위에 선택 창이 중앙 정렬되어 나타나고 전투 시간은 멈춰 있어야 한다. 카드를 누른 뒤 경험치 병 수 또는 보호막과 시간 진행을 확인한다. 도서관을 철거한 다음 다시 전투를 시작하면 선택 창이 열리지 않아야 한다.
