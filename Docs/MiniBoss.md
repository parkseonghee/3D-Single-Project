# 중간 보스와 즉시형 카드 (2026-10-11)

> 2026-10-12: 영웅 등급 **디아블로** 추가. 총 8종 중 중복 없이 3장 추첨. 상세 수치·기존 코드 재사용·에디터 설정은 [디아블로](Diablo.md) 참고. 아래 7종 설명은 디아블로 추가 이전 기록이다.

## 2026-10-12: 등급별 무작위 즉시 카드

기존 고정 3장을 아래 7종 중 중복 없는 무작위 3장으로 변경했다. 먼저 등급을 추첨한 뒤 해당 등급에 남은 카드 중 균등 선택한다. 일반 55 / 희귀 30 / 영웅 15 가중치이며 특정 등급 카드가 소진되면 남은 등급의 가중치로 다시 정규화한다. 따라서 이는 개별 카드 확률이나 한 화면의 확정 비율이 아니다. 가중치가 모두 0이면 남은 카드 중 균등 추첨한다.

| 등급 | 카드 | 효과 |
|---|---|---|
| 일반 | 경험치 보급 | 경험치 병 10개 |
| 일반 | 신속 | 지휘관·모든 병력 15초간 이동속도 +50% |
| 희귀 | 전장 폭발 | 화면 안 적에게 기본 피해 500 |
| 희귀 | 절대 보호 | 지휘관·생존 병력 5초 무적 |
| 희귀 | 긴급 치료 | 지휘관·생존 병력 HP 최대치로 회복, 부활 없음 |
| 영웅 | 지뢰밭 | 지휘관 주변 반경 4에 마법 함정 10개 설치 |
| 영웅 | 전투 함성 | 전 부대 20초간 공격력 +50%, 공격속도 +50% |

등급명과 카드 색상을 표시한다. 지뢰밭은 마법사/스킬 보유 여부와 무관하게 기존 함정·연기·메테오·범위·착탄 효과 및 피해 수치를 재사용한다. 대기 수명은 기존 마법 함정의 30초 설정을 따른다. 맵 가장자리는 바닥 범위 안으로 보정한다. 필수 함정 에셋 연결이 누락되면 추첨 풀에서 제외한다.

신속은 기존 진군의 나팔 배율에 곱해지며, 나팔이 끝나도 신속은 남은 시간 동안 유지된다. 전투 함성 공격력은 기존 공격력 버프에 곱하고 공격속도는 기존 공격속도 보너스에 가산한다. 공격속도 +50%는 기본 공격 간격을 1/1.5로 줄인다. 같은 카드 재사용 시 시간만 새로 갱신하며 효과량은 중첩하지 않는다. 게임 일시정지/카드 선택 중에는 지속 시간이 흐르지 않고 Run 종료 시 모두 해제한다.

설정: Recruitment System / MiniBossController의 Speed Duration/Bonus, War Cry Duration/Bonus, Common/Rare/Epic Weight. 스킬 카드 선택 UI와 별개의 즉시 보상 시스템이다.

검증: 2,000번의 3장 추첨에서 중복 0건. 지휘관·병사 완전 회복, 이동 배율 1.5, 공격력 배율 1.5/공격 간격 2/3, 마법사 없이 함정 10개 설치·적 접촉 후 메테오 낙하·피해를 Unity 실행에서 확인했다. 만료 시 원래 수치 복귀 및 Run 종료 초기화도 검증했다. 아래 고정 3장 설명은 이전 기록이다.

기획 근거: `Assets/Scripts/게임_기획서_최종.md` 6장 및 7.2절의 특수 적 처치 → 즉시형 카드. 예시는 화면 정리 폭발, 잠깐 전체 무적, 경험치 병 다발이다. 출현 시점과 수치는 미정이어서 아래 값을 임시 적용했다.

## 정예 오크

매 전투 생존 시간의 50%에 1마리 등장한다. 현재 구간 기본 오크 정의를 복제해 HP 5배, 공격력 1.5배, 모델 크기 1.5배로 만든다. 원본 에셋은 변경하지 않는다. 주황색 HP 바로 구분하며 기존 공격·사망 애니메이션과 피격/드롭 처리를 유지한다.

| Day | 등장 | HP | 공격력 | 속도 | 공격 간격 |
|---|---|---|---|---|---|
| 1~10 | 45초 | 300 | 15 | 2.3 | 1초 |
| 11~50 | 60초 | 450 | 15 | 2.3 | 1초 |
| 51~100 | 75초 | 700 | 15 | 2.3 | 1초 |

일반 적 제한 수와 별개로 한 번만 생성한다. 10일마다의 최종 보스와 독립적이며, 중간 보스 처치는 생존 클리어의 필수 조건이 아니다. 특수 자원은 지급하지 않는다.

## 처치 카드 3장 중 1장 선택

- 전장 폭발: 현재 메인 카메라 화면 안 살아 있는 적에게 500 기본 피해. 방어력 계산과 기존 피격·사망·드롭 처리를 따른다. 최종 보스도 피해 대상이다. 전용 폭발 VFX는 없고 기존 피격 효과를 사용한다.
- 절대 보호: 지휘관과 모든 생존 병력에게 5초 무적. 돌진 무적과 독립적으로 만료되고 다음 Run에서 초기화된다.
- 경험치 보급: 보유 경험치 병에 10개 즉시 추가한다. Ctrl+1~5 또는 기존 병 아이콘으로 원하는 병사에게 분배한다.

처치 직후 전투/타이머를 멈추고 선택 즉시 효과 적용 후 재개한다. 중복 선택을 막는다. 이미 병사 강화 선택 중이면 그 선택을 마친 뒤 표시한다. 준비 복귀/종료 시 선택 상태와 시간 배율을 복구한다.

## 설정과 파일

PlayScene / Recruitment System / MiniBossController에서 Spawn Progress, Health Multiplier, Damage Multiplier, Explosion Damage, Invulnerability Seconds, Bottle Reward를 조절한다. 폰트까지 연결해 두었으므로 수동 연결은 없다. 모델은 DaySettings.Stage.enemy를 재사용한다.

- MiniBossController.cs: 등장 시점·카드 UI·선택 상태.
- CombatController.cs 및 CombatController.InstantRewards.cs: 중간 보스 생성/처치 이벤트·광역 피해·아군 무적.
- DayController.cs: 구간 데이터 전달.
- BattleExperience.cs: 병 보상 추가 및 카드 선택 중 투자 차단.
- UnitHealth.cs: 시간제 무적.
- PlayScene.unity: 설정 컴포넌트와 한글 폰트 연결.

Unity 플레이에서 HP 300/공격력 15, 처치 후 카드 및 timeScale 0, 병 10개 지급, 중복 선택 차단, 무적 적용/만료, 화면 내 적 폭발 피해/처치, 카드 선택 중 준비 복귀 시 UI 종료·timeScale 1·선택 잠금 해제를 확인했다. 테스트 종료 콘솔 오류·경고 0건. 장시간 난이도 밸런스는 추가 플레이 조정 대상이다.
