# 모험 웨이브 리듬 · Day 성장 (2026-10-19)

선택된 방향은 섬멸/전술/보상 웨이브와 강약이 있는 전투 흐름이다. 별도 제한시간 돌파 보상이나 공격 방향 예고 기능은 이번 범위에 포함하지 않는다. 생존 모드는 기존 무한 웨이브 규칙을 유지한다.

## 90초 기준 흐름

| 시간 | 구간 | 생성 |
|---|---|---|
| 0~15초 | 탐색 | 가장 약한 적을 기본 간격마다 1명 |
| 15~30초 | 섬멸 | 가장 약한 적을 2초마다 4명, 체력 55%/공격력 65% |
| 30~40초 | 보상 | 일반 생성 중지. 30초에 중간 보스 등장, 처치 시 기존 즉시 카드 선택 |
| 40~60초 | 전술 | 기존 적 풀에서 가중 추첨, 기본 간격마다 2명, 정상 능력치 |
| 60~70초 | 정비 | 일반 생성 중지, 남은 적 처리/병 회수 |
| 70~90초 | 최종 섬멸 | 약한 적을 2초마다 6명, 체력 55%/공격력 65% |
| 생존 시간 이후 | 결전/정산 | 일반 생성 중지. 보스 Day는 기존 최종 보스 처치 조건 유지 |

120초/150초 전투는 위 시간 비율을 유지한다. 정비 때 이미 생성된 적을 제거하거나 무력화하지는 않는다. 보상 구간에서 보스를 처치하지 못하면 보스는 다음 구간에도 남는다.

## Day와 등장 패턴

- Day 1~10: 최대 2웨이브. 1웨이브는 탐색/섬멸/보상, 2웨이브는 전술/정비/최종 섬멸.
- Day 11~20: 최대 3웨이브. 최종 섬멸이 새 전선인 3웨이브.
- Day 21 이후: 최대 4웨이브. 최종 섬멸 전반/후반에 3/4웨이브.
- Day 1: 단일 전선에서 무리 진입.
- Day 5: 갈라진 전선(기준 방향 양쪽 40도) 해금.
- Day 11: 2웨이브부터 양면 협공(180도) 해금.
- Day 21: 3웨이브부터 네 방향 포위 해금.
- 첫 탐색 구간은 항상 단일 전선. 출전마다 시작 방향 무작위, 웨이브마다 전선 회전. 각 전선 내부는 ±12도 분산.
- 카메라 밖/지휘관과 거리 10 이상인 지점을 우선 탐색하고 맵 안으로 제한한다. 맵 경계에서 요청한 방향을 사용할 수 없으면 다른 방향을 탐색한다. 화면 밖 지형이 없으면 가장 먼 유효 지점을 사용한다.

## 능력치

Day 1 기준값에 가산하며 복리 적용하지 않는다. 원본 EnemyDefinition은 수정하지 않고 전투별 복제본에 적용한다. 기존 공유 몬스터 체력표는 Day 1 값을 기준으로 사용하여 Day 11/51의 체력 급증과 일일 성장이 중복되지 않도록 했다.

- 체력 배율: `1 + (Day - 1) × 0.04`
- 공격력 배율: `1 + (Day - 1) × 0.02`

| Day | 체력 | 공격력 |
|---|---:|---:|
| 1 | 1.00배 | 1.00배 |
| 10 | 1.36배 | 1.18배 |
| 20 | 1.76배 | 1.38배 |
| 30 | 2.16배 | 1.58배 |
| 100 | 4.96배 | 2.98배 |

일반/중간/최종 보스 모두 일일 성장이 적용된다. 중간 보스는 기존 별도 기본 체력과 공격력 1.5배 설정을 유지한다. 섬멸용 약화는 그 구간에 생성한 일반 적에게만 추가 적용하고, 다음 구간으로 넘어가도 이미 생성된 적의 능력치를 바꾸지 않는다.

섬멸 동시 개체 한도는 기본 24, 3웨이브 Day에서 28, 4웨이브 Day에서 32. 공통 Enemy Safety Limit을 넘지 않는다. 밀린 스폰을 한 프레임에 몰아 생성하지 않는다.

## 조정 / 코드

`Assets/CombatData/DaySettings.asset`에서 Health Per Day, Damage Per Day, Swarm Health/Damage Multiplier, Swarm Batch/Interval/Capacity, 패턴 해금 Day를 조절한다. 기존 waves/availableWaveCount는 구형 규칙용 호환 데이터이며 새 모험 흐름에는 사용하지 않는다. 전술/탐색의 기본 간격·한도·구성은 Stage 데이터를 사용한다.

- AdventureRhythmRule.cs: 시간 흐름, 배치, 적 선택, 전선 방향.
- CombatController.cs/Spawning.cs: 기존 풀링/피해 처리를 재사용하며 생성 위치·개별 약화 배율 적용.
- DayController.cs: Day별 런타임 능력치, 새 규칙 연결, 좌상단 현재 구간/패턴 표시.
- MiniBossController.cs: 모험 중간 보스 출현 시간을 보상 구간 시작으로 지정. 생존 모드 정예 타이밍은 그대로.
- Editor/AdventureWaveVerification.cs: Tools > Army Survivor > Verify Adventure Waves.

검증 메뉴는 Day 1~100의 웨이브 수, 능력치 증가, 패턴 해금, 생성 한도, 정비 중 생성 중지, 최종 보스 구간, 90초 타임라인을 확인한다. 실제 전체 전투의 이동/처치 속도와 난이도는 플레이 밸런스 조정 대상이다.
