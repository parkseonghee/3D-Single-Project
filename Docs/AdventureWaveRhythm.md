# 모험 웨이브 리듬 · Day 성장 (2026-10-19)

선택된 방향은 섬멸/전술/보상 웨이브와 강약이 있는 전투 흐름이다. 별도 제한시간 돌파 보상이나 공격 방향 예고 기능은 이번 범위에 포함하지 않는다. 생존 모드는 기존 무한 웨이브 규칙을 유지한다.

## 90초 기준 흐름

| 시간 | 구간 | 생성 |
|---|---|---|
| 0~15초 | 탐색 | 적 풀에서 가중 추첨, 기본 간격마다 1명 |
| 15~30초 | 섬멸 | 적 풀에서 가중 추첨, 2초마다 4명, 체력 55%/공격력 65% |
| 30~40초 | 보상 | 일반 생성 중지. 30초에 중간 보스 등장, 처치 시 기존 즉시 카드 선택 |
| 40~45초, 54~60초 | 전술 | 기존 적 풀에서 가중 추첨, 기본 간격마다 2명, 정상 능력치 |
| 45~54초 | 특별 웨이브 | 무작위 패턴 이름을 먼저 표시하고 1.25초 후 해당 진형으로 등장 |
| 60~70초 | 정비 | 일반 생성 중지, 남은 적 처리/병 회수 |
| 70~90초 | 최종 섬멸 | 적 풀에서 가중 추첨, 2초마다 6명, 체력 55%/공격력 65% |
| 생존 시간 이후 | 결전/정산 | 일반 생성 중지. 보스 Day는 기존 최종 보스 처치 조건 유지 |

> **2026-11-13 변경:** 탐색·섬멸·최종 섬멸은 원래 체력이 가장 낮은 적만 생성했다. 닌자(체력 최저, 이동 속도 최고)가 추가되면서 전장 생성량의 90% 이상이 닌자가 되었고, 출전 미리보기 비율과 어긋났으며 가중치형 전장 변수의 효과도 거의 없었다. 지금은 모든 구간이 `DaySettings.Stage.enemies` 가중치(전장 변수 배율 포함)로 추첨한다. 섬멸 구간 약화(체력 55%/공격력 65%)는 그대로 유지한다. 시뮬레이션(각 Day 20회)에서 실제 비율이 미리보기 비율과 ±2% 이내로 일치했다.

120초/150초 전투는 위 시간 비율을 유지한다. 정비 때 이미 생성된 적을 제거하거나 무력화하지는 않는다. 보상 구간에서 보스를 처치하지 못하면 보스는 다음 구간에도 남는다.

특별 웨이브는 해당 Day의 50% 시점에 시작한다. 화면 상단에 패턴 이름을 알리고 1.25초 뒤 첫 몬스터를 생성한다. 패턴에 따라 후속 몬스터는 0~3초에 걸쳐 순차 등장한다. 특별 웨이브 동안 일반 배치 생성은 중지하고, 등장한 적의 체력은 70%, 공격력은 80%로 조절한다. 동시 생성 한도는 해당 Stage 한도에 특별 웨이브 수만큼 임시로 더하며 공통 안전 상한을 넘지 않는다. 원형 진형은 지휘관을 따라 반경을 초당 1.5m씩 줄이고 3.5m에서 기존 AI로 전환한다. 해당 Day에는 특별 웨이브가 한 번만 나온다.

## 특별 웨이브 16종

Day 1~4는 앞의 5종, Day 5~10은 앞의 11종, Day 11 이후에는 16종 중 무작위로 한 종류를 고른다. 배치 인원은 공통 Special Wave Count를 따른다.

| 패턴 | 동작 |
|---|---|
| 원형 포위 | 지휘관 주위 원형 생성 후 서서히 접근 |
| 양면 동시 돌격 | 서로 반대 방향 두 전선에서 진입 |
| 부채꼴 돌격 | 한쪽 150도 호에 흩어져 진입 |
| 후방 기습 | 한 전선의 반대쪽에서 빠르게 진입 |
| 좁혀오는 고리 | 세 겹 원을 시간차로 생성하고 서서히 접근 |
| 십자 압박 | 네 방향에서 세 차례 시간차 진입 |
| 나선 진입 | 각도를 회전하며 한 명씩 연속 진입 |
| 미끼와 본대 | 약한 첫 무리 뒤에 반대편 강한 무리 등장 |
| 정예 호위대 | 체력 높은 정예형 일반 몬스터 한 마리와 호위 병력 |
| 원거리 포위망 | 원거리 적은 바깥에, 근접 적은 안쪽에 생성 |
| 추격 열차 | 같은 방향에서 세 줄이 순차 진입 |
| 양쪽 교대 공격 | 좌우에서 번갈아 진입 |
| 틈새 돌파 | 90도 열린 틈을 남긴 원호 포위 |
| 지휘관 사냥 | 빠른 적이 병사를 무시하고 지휘관을 추적 |
| 포위 후 돌격 | 포위 위치에 잠시 머문 뒤 함께 접근 |
| 정예 증원 | 첫 전선 뒤 반대쪽에 정예형 일반 몬스터와 증원 등장 |

정예 패턴은 해당 Day에 설정된 정예 몬스터 정의를 사용하고 처치 시 기존 즉시 카드 보상을 준다. 정예 정의가 없으면 일반 몬스터를 1.3배 크게 표시하고 체력을 추가로 증폭한다. 원거리 적이 해당 Day의 적 풀에 없으면 일반 적으로 대체한다.

## Day와 등장 패턴

- Day 1~10: 최대 2웨이브. 1웨이브는 탐색/섬멸/보상, 2웨이브는 전술/정비/최종 섬멸.
- Day 11~20: 최대 3웨이브. 최종 섬멸이 새 전선인 3웨이브.
- Day 21 이후: 최대 4웨이브. 최종 섬멸 전반/후반에 3/4웨이브.
- Day 1: 단일 전선에서 무리 진입.
- Day 5: 갈라진 전선(기준 방향 양쪽 40도) 해금.
- Day 11: 2웨이브부터 양면 협공(180도) 해금.
- Day 21: 3웨이브부터 네 방향 포위 해금.
- 첫 탐색 구간은 항상 단일 전선. 출전마다 시작 방향 무작위, 웨이브마다 전선 회전. 각 전선 내부는 기본 90도 폭의 호에서 순서대로 분산한다. 생성 묶음 안에서도 서로 다른 각도를 쓴다.
- 카메라 밖/지휘관과 거리 10 이상인 지점을 우선 탐색하고 맵 안으로 제한한다. 최근 생성 지점 16개와 기본 3.5m 이상 떨어진 곳을 우선하며, 경계에 막히면 요청 전선의 인접 각도를 탐색한다. 화면 밖 지형이 없으면 가장 나은 유효 지점을 사용한다.

## 능력치

Day 1 기준값에 가산하며 복리 적용하지 않는다. 원본 EnemyDefinition은 수정하지 않고 전투별 복제본에 적용한다. 기존 공유 몬스터 체력표는 Day 1 값을 기준으로 사용하여 Day 11/51의 체력 급증과 일일 성장이 중복되지 않도록 했다.

- 체력 배율: `1 + (Day - 1) × 0.04`
- 공격력 배율: `1 + (Day - 1) × 0.02`

| Day | 체력 | 공격력 |
|---|---:|---:|
| 1 | 1.00배 | 1.00배 |
| 10 | 1.36배 | 1.18배 |
| 20 | 1.76배 | 1.38배 |
| 30 | 2.16배 | 1.58배 |
| 100 | 4.96배 | 2.98배 |

일반/중간/최종 보스 모두 일일 성장이 적용된다. 중간 보스는 기존 별도 기본 체력과 공격력 1.5배 설정을 유지한다. 섬멸용 약화는 그 구간에 생성한 일반 적에게만 추가 적용하고, 다음 구간으로 넘어가도 이미 생성된 적의 능력치를 바꾸지 않는다.

섬멸 동시 개체 한도는 기본 24, 3웨이브 Day에서 28, 4웨이브 Day에서 32. 공통 Enemy Safety Limit을 넘지 않는다. 밀린 스폰을 한 프레임에 몰아 생성하지 않는다.

## 조정 / 코드

`Assets/CombatData/DaySettings.asset`에서 Health Per Day, Damage Per Day, Swarm Health/Damage Multiplier, Swarm Batch/Interval/Capacity, 패턴 해금 Day와 Spawn Arc Degrees/Spawn Separation을 조절한다. Special Wave Start/Duration Progress, Count, Health/Damage Multiplier로 특별 웨이브의 시점·규모·강도를 조절한다. Special Wave Warning Seconds와 Encirclement Spawn Radius/Closing Speed/Release Radius, Special Elite Health Multiplier를 조절할 수 있다. 기존 waves/availableWaveCount는 구형 규칙용 호환 데이터이며 새 모험 흐름에는 사용하지 않는다. 전술/탐색의 기본 간격·한도·구성은 Stage 데이터를 사용한다.

- AdventureRhythmRule.cs: 시간 흐름, 배치, 적 선택, 전선 방향.
- CombatController.cs/Spawning.cs: 기존 풀링/피해 처리를 재사용하며 생성 위치·개별 약화 배율 적용.
- DayController.cs: Day별 런타임 능력치, 새 규칙 연결, 좌상단 현재 구간/패턴 표시.
- MiniBossController.cs: 모험 중간 보스 출현 시간을 보상 구간 시작으로 지정. 생존 모드 정예 타이밍은 그대로.
- Editor/AdventureWaveVerification.cs: Tools > Army Survivor > Verify Adventure Waves.

검증 메뉴는 Day 1~100의 웨이브 수, 능력치 증가, 패턴 해금, 생성 한도, 정비 중 생성 중지, 최종 보스 구간, 특별 웨이브 하루 한 번 구간·16종 진형, 90초 타임라인을 확인한다.

### 플레이 테스트

Unity 메뉴 `Tools > Army Survivor > Special Wave Test`를 연다. 패턴을 선택하고 `다음 모험 전투 패턴 고정`을 누른 뒤 모험 모드 전투를 시작하면 해당 패턴을 볼 수 있다. 전투 도중에는 `선택한 웨이브 지금 소환`을 누르면 선택한 패턴이 예고 후 등장한다. 같은 창의 `16종 자동 검증`은 데이터와 진형을 검사한다. 고정은 플레이 모드 종료 시 해제된다. Day 11 이상에서는 전체 패턴을 자연 등장으로 확인할 수 있다. 실제 이동·처치 속도와 난이도는 플레이 밸런스 조정 대상이다.
