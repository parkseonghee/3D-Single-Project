# 마을 앞쪽 건설 부지

- VillageScene의 `Village Castle Landscape/Front Construction Plot`이 새 건설 부지입니다.
- 월드 범위 X -24~24, Z -60~-24, 크기 48×36입니다. 기존 2단위 격자로 24×18칸입니다.
- `Village Hex Map`의 BoxCollider를 이 부지 크기와 위치에 맞춰 실제 건설/이동 확정 범위를 제한했습니다. 상단 성·기존 주택·주민 보행로에는 새 건물을 배치할 수 없습니다.
- 시작 농장은 앞쪽 부지 (-12, 0, -32), 막사는 (9, 0, -31)에 각각 1개씩 미리 배치했습니다. 중앙의 큰 성은 경관으로 분리하여 저장/철거와 무관하게 유지합니다.
- 새 게임 초기 생산량은 농장 하루 벼 100 + 막사 하루 벼 40 = 140입니다. 기존 수확 버튼으로 하루 4회, 회당 35씩 받습니다. 막사를 추가 건설하면 하루 20, 강화마다 10이 추가됩니다.
- 앞쪽 부지와 겹치는 나무·바위 6개는 양옆으로 이동했습니다.
- 카메라 시작 구도는 부지와 성을 함께 내려다보도록 조정했습니다. 마우스 드래그로 앞쪽 부지까지 이동할 수 있습니다.
- 씬을 재생성할 때도 `VillageBackdropSetup`이 `VillageFrontPlotSetup.Apply()`를 호출해 이 배치를 유지합니다. 수동 재적용 메뉴는 `Army Survivor > Village > Configure Front Construction Plot`입니다.

## 검증 범위

MCP 재연결 후 Unity Play Mode에서 확인했습니다.

- 부지 중앙 병영(Workshop) 건설 성공 및 벼 110 차감.
- 부지 밖과 경계에 걸친 건물 배치 차단.
- 건설된 위치의 중복 배치 차단.
- 초기 농장/막사 모두 등록되고 일일 수확량 140 및 1회 수확 35를 확인했습니다.
- 실행 콘솔 오류 0건, 실제 게임 화면에서 초기 건물 2개와 나머지 빈 흙 부지 확인.
- 테스트 종료 후 편집 모드로 돌아왔으며 테스트 건물은 씬에 저장하지 않았습니다.

기존 저장 슬롯에 저장된 건물 위치는 강제로 변경하지 않습니다.
