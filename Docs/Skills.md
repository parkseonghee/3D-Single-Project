# 구현된 병종별 스킬

기준일: 2026-10-05. `BattleExperience`, `CombatController`와 분할 스크립트, `Assets/ArmyData`의 습득 허용 설정, `PlayScene`의 저장된 수치를 대조했다. 기본 공격을 제외한 습득 스킬은 **24개**다. 아래 수치는 현재 임시 밸런스이며 최종 확정값이 아니다.

## 공통 성장 규칙

- 경험치 병은 원하는 출전 유닛에게 개별 투자한다. 같은 병종이라도 레벨·경험치·스킬은 공유하지 않는다.
- 병 1개는 100 EXP, 다음 레벨 요구량은 `100 × (현재 레벨 + 2)`다.
- 레벨업마다 습득·강화 가능한 스킬 후보 중 최대 3장을 무작위 표시하고 1장을 선택한다. 최대 강화에 도달한 스킬은 후보에서 빠진다.
- 후보가 1~2개면 그 수만 표시하며, 더 배울 스킬이 없으면 선택 화면을 건너뛴다.
- 선택 중 전투가 멈추며, 전장 종료 시 스킬·경험치·레벨은 초기화된다. 영구 강화가 아니다.
- 아래 '1회'는 습득 후 추가 레벨업 카드가 없는 스킬이다. 자동 발동 횟수가 1회라는 뜻이 아니다.
- 공격력·공격속도·체력의 일반 능력치 강화 카드는 현재 후보에서 제거돼 있다.

## 현재 카드에 없는 기존 기획

다음은 과거 아이디어이며 현재 습득 가능한 스킬로 세면 안 된다: 병사의 관통 검기·대지 가르기·광폭화, 궁수 유도 화살, 방패병 가시 오라·도발, 마법사 별도 불장판·냉기 새장. 메테오는 현재 마법 함정에 통합되어 별도 카드가 아니고, 기마병 자동 돌진은 기본 공격이다.

## 수정 위치와 확인 범위

- 병종별 습득 허용: `Assets/ArmyData/*.asset`의 `canLearn...`.
- 수치·이펙트: `PlayScene`의 `Recruitment System > CombatController`.
- 최대 강화·회복률·카드 연결: 같은 오브젝트의 `BattleExperience`.
- 기본 공격: `Assets/CombatData/*`의 `AttackDefinition` 에셋.
- 스킬별 동작: `Assets/Scripts/Army/CombatController*.cs`, 카드와 성장: `BattleExperience.cs`.
- 이번 갱신은 코드·직렬화된 씬·병종 에셋 대조에 따른 문서 정리다. 모든 스킬의 장시간 플레이·밸런스를 새로 검증한 것은 아니다.
