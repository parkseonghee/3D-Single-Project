# 전투 성능 최적화 (2026-11-16)

## 측정 (에디터, 서바이벌, 몬스터 약 150~200마리 + 경험치 병 128개)

- 전투 스크립트 전체(Tick): 약 0.5ms, 프레임당 메모리 할당 0. 경험치 병 처리 0.02ms. 스크립트는 병목이 아니다.
- 그리기 비용(하나씩 끄며 비교): 몬스터 그리기 약 3.6ms, 몬스터 애니메이션 약 1.1ms, 경험치 병 약 0.8ms.
- 몬스터 그림자는 약 0.5ms. 그림자 단계 수는 환경설정 그래픽 품질(높음 4단계/중간 2단계/낮음 1단계)로 고른다.
- 배경(숲·산·물 390개, 약 5.9만 삼각형)과 바닥 타일(187개, 약 6천 삼각형)은 가볍다. 프로파일러에 크게 보이는 수치는 정적 배칭으로 합쳐진 메시 크기다.
- 경험치 병 모델(7,387 삼각형)을 기존 정점 군집 방식으로 더 줄이면 표면에 구멍이 생겨 줄이지 않았다.

## 적용한 것

| 항목 | 내용 | 조정 |
|---|---|---|
| 몬스터 체력바 | 일반 몬스터는 다친 뒤에만 보인다. 정예·보스·아군은 항상 보인다. 200마리 기준 활성 체력바 206개 → 6개 | CombatController `Hide Full Health Enemy Bars` |
| 몬스터 애니메이션 | 화면 밖 몬스터는 뼈대 갱신을 생략한다(상태·공격 타이밍은 유지) | CombatController `Enemy Animator Culling` |
| 이펙트 재사용 | 피 이펙트, 아군·적·디아블로 투사체, 근접 공격 이펙트, 화살 폭발을 매번 생성/파괴하지 않고 재사용한다. 10초 피격 144회에 오브젝트 74개만 생성 | `CombatController.EffectPool.cs` |

이펙트 풀: `SpawnEffect`로 꺼내고 `ReleaseEffect` / `ReleaseEffectAfter`로 돌려놓는다. 재사용 시 크기·파티클·궤적을 처음 상태로 되돌린다. 전투 정리(`Clear`) 때 쓰던 이펙트를 풀로 돌려놓은 뒤 전투 루트를 파괴한다. 풀에서 만들지 않은 오브젝트를 `ReleaseEffect`에 넘기면 그대로 파괴한다.

## 정리한 에셋

사운드 팩(Card_Game, Casual Game Sounds U6, Whooshes SFX Pack)에서 빌드 씬·Resources·프리팹·ScriptableObject 어디에서도 참조하지 않는 소리 553개(약 269MB)를 지웠다. 사용 중인 25개는 남겼다. 안 쓰는 에셋은 원래 빌드에 포함되지 않으므로 프레임과는 무관하고 프로젝트 용량·임포트 시간만 줄어든다. 모델·이펙트 팩의 미사용 에셋(약 580MB)은 남겨 두었다.
