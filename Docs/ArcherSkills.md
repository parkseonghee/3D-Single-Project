## 관통 동작과 코드

MeshyArcherArrow의 모델 자식 Scale을 (100,100,100)으로 설정했다. 꼬리 궤적 위치는 Z=-0.9로 조정했다. 모델 길이는 약 1.95 Unity 단위다.

UnitDefinition.canLearnPiercing을 궁수 데이터에만 켰다. 이름 문자열로 병종을 판단하지 않는다. BattleExperience는 개체별 UnitProgress.Piercing을 기록한다. 기존 능력치 카드 3개에 습득 가능한 궁수만 네 번째 관통 카드를 표시한다. 습득 뒤 카드가 사라지고 코드에서도 중복 선택을 거부한다. 같은 편성의 다른 궁수에게는 적용하지 않는다. 기존 전장 강화 정책에 따라 전장 종료 시 초기화되고 영구 저장하지 않는다.

CombatController는 발사 시 습득 여부를 투사체에 복사한다. 일반 화살은 기존 사거리와 첫 적 소멸 규칙을 유지한다. 관통 화살의 조준 범위와 피해량은 기존 값을 유지하고 비행 거리만 Ground.bounds의 XZ 외곽 경계까지 연장한다. 현재 '벽 끝'은 사각 전장의 외곽을 뜻한다. 별도 내부 벽 콜라이더 충돌은 구현하지 않았다.

각 화살의 HashSet에 이미 맞은 적을 기록한다. 이동 선분 안의 모든 적을 처리하므로 빠른 화살도 한 프레임에 여러 적을 관통하며, 같은 적에게 다음 프레임에 다시 피해를 주지 않는다. 전장 경계에 도달하면 소멸한다.

## 밸런스 판단

일렬로 몰리는 적에 강한 역할이 명확하여 프로토타입 스킬로 적합하다. 다만 무제한 관통과 긴 비행 거리를 동시에 얻으므로 단일 대상 공격력 +20%보다 군집 상황에서 훨씬 강할 수 있다. 현재는 피해량 추가 보너스 없이 요청한 기능을 적용했다. 멀티샷·폭발 화살과 결합하면 효과가 크게 증가하므로 결합 시 별도 검증이 필요하다.

테스트 후 너무 강하면 추가 대상의 피해 감쇠나 발동 주기 제한 중 하나부터 도입하는 편이 좋다. 이는 제안이며 현재 코드에 임의로 적용하지 않았다. 기존 기획의 '관통 수 증가'는 이미 무제한인 새 방식과 맞지 않아 제거했다.

## 검증

Unity Play 모드에서 경험치 투자로 궁수 레벨업 화면과 카드 표시를 확인했다. 카드 콜백 선택 후 궁수 1명에게만 적용되는지, 중복 선택 거부와 전장 종료 초기화를 검증했다. 통제된 적·투사체를 구성해 일직선 적 2명 관통, 옆 적 제외, 동일 적 중복 피해 방지, 비행 거리 소진 정리, 전장 경계 거리 계산을 검증했다. 콘솔 오류·경고 없음. 물리 마우스 입력 및 장시간 밸런스 테스트는 하지 않았다.
