# 전장 경험치 병

## 레벨업 카드 (2026-09-24 추가)

- 병력별 레벨업 시 3장 중 하나를 선택합니다. 해당 병력에만 적용됩니다.
- 공격력: 기본 공격력의 20%씩 가산. 공격 속도: 기본 공격 속도의 15%씩 가산.
- 체력: 기본 최대 체력의 25%씩 증가하고 증가분만큼 회복합니다.
- 선택 중 전투와 Day 타이머를 멈추고, 연속 레벨업은 순서대로 처리합니다.
- 전장 종료 시 선택 대기열과 강화가 초기화되고 기존 시간 배율을 복구합니다.
- Recruitment System/BattleExperience에서 수치를, Level Up Cards의 TMP에서 고정 문구를 수정할 수 있습니다. 수치를 바꾸면 카드 문구도 함께 수정하세요.
- 이번 카드는 기본 능력치 강화 3종입니다. 회전검 등 병종별 신규 스킬 카드는 아직 구현하지 않았습니다.
- 검증: Unity 참조 DLL로 C# 컴파일 성공, 씬 객체 ID/카드 참조 확인. MCP 부재로 에디터 플레이 검증은 미실시.

## 2026-09-24 변경 (아래 기존 기록보다 우선)

- 하단 병력 카드마다 독립적으로 경험치를 투자합니다. 같은 병사 1번과 2번도 레벨·EXP가 분리됩니다.
- UnitDefinition은 병종 이름·기본 설정에만 사용하고, 성장 상태는 출전 유닛 Transform별로 보관합니다.
- 병력 카드: 이름·번호, 레벨/EXP, 게이지, '병 먹이기 +100'. 전투불능 병력은 투자를 비활성화합니다.
- UnitLeveledUp(Transform, int) 이벤트로 개별 병력의 레벨업을 알립니다. 이전 ClassLeveledUp은 제거했습니다.
- 밀집·전개·산개는 하단 카드 위 작은 버튼으로 배치합니다.
- 현재 편성 상한 5명에 맞춘 5개 카드입니다.

## 이전 구현 기록

기준: 게임_기획서_최종.md 4.5, 8.1.

- 적을 처치하면 청록색 큐브 경험치 병 1개를 떨어뜨립니다.
- 지휘관이 반경 1.2 안으로 접근하면 수집합니다. 병력은 수집하지 않습니다.
- 전투 중 왼쪽 패널에서 출전 클래스의 '병 1개 사용'을 누릅니다.
- 병 1개는 100 EXP입니다. 클래스는 Lv.1로 시작하고 다음 레벨 요구량은 100 × (현재 레벨 + 2)입니다. 초과 EXP는 유지합니다.
- 같은 UnitDefinition을 사용하는 병력은 레벨과 EXP를 공유합니다. 전투불능이 되어도 해당 전장의 성장 기록은 유지합니다.
- 전장 종료(준비 복귀, 패배, 클리어) 시 병, 드롭, 클래스 성장은 초기화됩니다. 저장 대상이 아닙니다.

## 수정 위치

- Recruitment System / BattleExperience: 수집 반경, 병당 EXP, 클래스별 UI 연결.
- Assets/Prefabs/Combat/ExperienceBottle.prefab: 임시 큐브. 추후 병 모델로 교체.
- Recruitment UI / Experience Panel: 고정 문구는 TMP에서 직접 수정. 코드에서는 수량·레벨·EXP만 갱신.
- BattleExperience.ClassLeveledUp: 클래스 레벨업 이벤트. 스킬 드래프트는 아직 연결하지 않았으며, 이번 구현은 경험치 수집·투자·레벨 관리까지입니다. 레벨만으로 임의 능력치 보너스를 지급하지 않습니다.
