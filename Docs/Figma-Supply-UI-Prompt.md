# 피그마 디자인 요청: 왕국 보급소 · 장비 뽑기 UI

PC용 3D 중세 판타지 게임의 ‘왕국 보급소 · 장비 뽑기’ 화면을 디자인해줘.

## 첨부 이미지의 역할
- 첫 번째 이미지: 젠레스 존 제로 뽑기 화면. 큰 메인 비주얼, 비대칭 구성, 강한 타이포그래피, 하단 뽑기 버튼 배치를 참고한다.
- 두 번째 이미지: 현재 개발 중인 게임 화면. 아이템 목록, 인장 재화, 3D 관찰, 보급 기능을 유지한다.
- 첫 번째 이미지의 캐릭터·로고·문구를 그대로 사용하지 말고, 우리 게임의 무기와 왕국 문양으로 재해석한다.

## 디자인 목표
현재의 단순한 사각형 버튼과 텍스트 목록을 완성도 높은 게임 UI로 개선한다.
화면에 들어왔을 때 ‘대표 무기 → 장비 이름과 등급 → 뽑기 버튼’ 순서로 시선이 이동해야 한다.
웹사이트나 관리자 대시보드처럼 보이지 않게 한다.

## 세계관과 분위기
- 파란 깃발과 금빛 왕국 문양을 사용하는 중세 판타지.
- 왕국 무기고에서 인장을 사용해 장비를 보급받는 콘셉트.
- 짙은 남색, 먹색, 은색, 절제된 금색을 기본으로 사용한다.
- 붉은 보석 인장을 재화의 핵심 시각 요소로 사용한다.
- ZZZ의 대담한 구성과 사선 요소를 참고하되 네온, 현대 도시 그래피티, SF 장식은 사용하지 않는다.
- 낡은 금속, 깃발 천, 문장 패턴을 은은하게 활용한다.
- 과한 양피지 배경이나 두꺼운 금색 테두리는 피한다.

## 프레임
- 1920×1080, 16:9 PC 게임 화면.
- 바깥 안전 여백 40px 이상.
- 모든 사용자 노출 텍스트는 한국어.
- 주요 설명은 22~26px 수준으로 읽기 쉽게 구성한다.

## 화면 배치

### 1. 상단
- 좌측: 뒤로가기 아이콘과 ‘돌아가기’.
- 옆에 화면 제목 ‘왕국 보급소’.
- 우측: 붉은 보석 인장 아이콘 + ‘보급 인장’ + 보유 수량.
- 재화 표시는 하나만 둔다.
- 상단 바가 대표 무기보다 시선을 강하게 끌지 않게 한다.

### 2. 좌측 장비 도감
- 화면 폭의 약 20%를 사용한다.
- 제목: ‘보급 장비’.
- 각 행에 작은 무기 썸네일, 등급 배지, 장비 이름, 보유 상태를 표시한다.
- 선택된 행은 밝은 가장자리와 작은 왕국 문양으로 명확히 구분한다.
- 미보유 장비도 선택해 미리 볼 수 있다.
- 선택은 관찰 대상만 변경한다. 선택한 무기가 확정 지급되거나 확률이 올라간다는 인상을 주지 않는다.

| 등급 | 장비 이름 |
|---|---|
| C | 훈련용 검 |
| C | 수비대 방패 |
| B | 현자의 지팡이 |
| B | 왕실의 대검 |
| A | 에테르스톰 블레이드 |
| A | 화려한 마법 지팡이 |
| A | 공허의 방패 |
| S | 프로스트바이트 단검 |

- 등급 색상: C 회색, B 청록, A 보라, S 금색.
- 색상 외에도 C/B/A/S 문자를 반드시 표시한다.

### 3. 중앙 대표 무기
- 화면에서 가장 큰 비주얼 영역으로 사용한다.
- 기본 선택 장비는 S급 ‘프로스트바이트 단검’.
- 첨부한 두 번째 이미지의 은색 곡선형 단검과 푸른 보석 형태를 참고한다.
- 무기를 대각선으로 크게 배치하되 끝부분이 잘리지 않게 한다.
- 배경은 어두운 왕국 문양과 은은한 서리 입자로 구성한다.
- 커다란 장식용 S 문자를 무기 뒤에 낮은 불투명도로 배치할 수 있다.
- 이 영역은 Unity에서 실시간 3D 모델이 표시될 자리다. 무기 이미지와 배경 장식은 별도 레이어로 분리한다.
- 하단에 작게 ‘드래그하여 회전 · 휠로 확대/축소’.
- 그 옆에 작은 ‘시점 초기화’ 버튼.
- 주변 장식이 무기를 가리거나 조작 영역을 막지 않게 한다.

### 4. 우측 장비 정보
- 화면 폭의 약 25%를 사용한다.
- ‘S급 장비’ 배지.
- 큰 제목 ‘프로스트바이트 단검’.
- 짧은 설명: ‘서리의 기운을 품은 왕국의 희귀 단검.’
- 상태: ‘미보유 · 미리보기’.
- 안내: ‘획득한 장비는 출전 준비에서 장착할 수 있습니다.’
- 아이템 능력은 아직 확정 전이므로 임의의 공격력이나 특수 능력을 추가하지 않는다.
- 긴 설명 박스를 여러 개 쌓지 않고 정보의 중요도에 따라 여백을 둔다.

### 5. 하단 보급 영역
- 화면 하단에 안정적으로 고정된 액션 영역을 만든다.
- 우측에 ‘1회 보급’과 ‘10회 보급’ 버튼을 나란히 배치한다.
- 각 버튼에 붉은 보석 인장 아이콘과 비용 ‘×1’, ‘×10’을 표시한다.
- ‘10회 보급’을 주 버튼으로 강조하되 번쩍이는 효과는 과하지 않게 한다.
- 버튼 위에는 ‘10회 이내 A급 이상 보장’, ‘90회 이내 S급 보장’을 표시한다.
- 실제 누적 횟수에 따라 남은 횟수로 바뀔 수 있는 텍스트 영역으로 만든다.
- 좌측에는 ‘확률 안내’와 ‘보유 장비’ 보조 버튼을 배치한다.
- ‘관찰 중인 장비와 관계없이 전체 장비 풀에서 무작위 보급됩니다.’를 작은 안내로 표시한다.

## 확률 안내 모달
- S 0.6% / A 9.4% / B 30.0% / C 60.0%.
- 기본 확률이며 보장 적용 회차에는 달라질 수 있음을 표시한다.
- 기간 한정, 픽업 확률 증가, 할인, 유료 재화 구매 기능은 추가하지 않는다.

## 컴포넌트와 상태
다음 요소를 재사용 가능한 컴포넌트로 만든다.
- 장비 목록 행: 기본 / 호버 / 선택 / 미보유.
- 보급 버튼: 기본 / 호버 / 눌림 / 인장 부족으로 비활성화.
- 등급 배지: C / B / A / S.
- 인장 재화 표시.
- 보조 버튼과 확률 안내 모달.

호버 시에는 밝기 변화, 얇은 테두리, 작은 문양 등장으로 반응을 표현한다.
선택 상태와 호버 상태는 서로 구별되게 한다.

## 프로토타입 흐름
- 장비 목록 선택 → 중앙 무기와 우측 정보 변경.
- 확률 안내 → 모달 열기/닫기.
- 보급 버튼 → ‘성문 접근·폭죽·문 열기 연출’ 연결용 화면.
- 실제 3D 연출은 Unity에서 구현하므로 Figma에서는 전환 위치만 표현한다.
- 인장 부족 상태에서는 보급 실행을 막고 부족한 수량을 안내한다.

## 제작 구조
- 편집 가능한 텍스트, 아이콘, 배경, 무기 이미지를 분리한다.
- Auto Layout과 재사용 가능한 색상·텍스트 스타일을 사용한다.
- 3D 무기 영역은 크기가 명확한 독립 프레임으로 만든다.
- Unity uGUI로 옮기기 쉽도록 복잡한 마스크와 중첩 블러를 최소화한다.
- 배경이나 버튼에 텍스트를 이미지로 합치지 않는다.

## 최종 요청
완성도 높은 메인 화면 1개를 먼저 만들고, 같은 디자인의 ‘인장 부족 상태’와 ‘확률 안내 모달’을 추가로 보여줘.
