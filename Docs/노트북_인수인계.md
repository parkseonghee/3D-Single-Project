# 노트북 작업 인수인계 · 2026-09-13

## 프로젝트와 작업 원칙
- Unity 6000.3.18f1 / URP / Input System. 중세 3D 군대 서바이버: 마을 건설 → 병력 고용·편성 → 전투가 목표.
- 기획 기준: `Assets/Scripts/게임_기획서_최종.md`. 현재는 건설·고용 준비 단계까지 구현.
- **읽기 쉬운 짧은 코드, 적은 클래스, Inspector 연결을 우선한다.** 불필요한 추상화나 병종 이름에 따른 하드코딩을 추가하지 않는다.
- **UI는 TextMeshPro. 고정 문구와 폰트를 실행 중 코드로 덮어쓰지 않는다.** 사용자가 Inspector에서 직접 입력한다.
- 예외: 사용자 요청으로 **PlayScene의 보유 벼 숫자만 자동 갱신**한다. ‘벼’ 라벨은 별도 TMP.
- 외부 에셋 원본은 보존하고, 프로젝트용 프리팹·설정 에셋을 사용한다. Unity 변경 후 콘솔과 실제 화면을 확인한다.

## 현재 구현
- `VillageScene`: 바닥에 건물 선택·미리보기·클릭 건설. 경계/겹침/식량 검사, 비용 차감, 반복 건설 비용 증가. 우클릭/Esc 취소.
- 왼쪽 아래 건설하기 → 가로 스크롤 건물 카드 목록. Kenney UI Pack – Adventure 적용. 하단 안내 바와 안내 문자열 코드는 사용자 요청으로 삭제했다.
- 오른쪽 아래 준비 → `PlayScene`. 오른쪽에 병력 고용 목록, 중앙에 TT_King 지휘관, 근처 5개 자리로 고용 병력이 짧은 크기 효과와 함께 등장한다.
- 필요한 건물 미건설/식량 부족/편성 가득 참이면 고용 차단. 뒤로가기로 마을 복귀.
- 두 씬을 추가 로드 후 표시 전환하므로 **동일 실행 중 건물·식량·고용 병력 유지**. 지휘관 제외 초기 고용 상한 5명.
- 준비 화면 상단 보유 벼는 진입·고용·재진입 시 갱신. 카메라는 낮고 가까운 Perspective, FOV 40으로 조정해 캐릭터가 크게 보인다.

## 현재 상태와 주의점
- 사용자 Inspector 설정으로 **Starting Rice = 999999**. 임의로 320으로 되돌리지 않는다.
- 마을의 기존 벼 표시와 카드 가격은 수동 문구다. 실제 비용 데이터를 바꾸면 카드 문구도 직접 수정해야 한다.
- Scene Travel은 항상 활성 상태여야 하며 Village Roots 배열에 자기 자신을 넣지 않는다.
- PlayScene 직접 실행 시 마을 자원 정보가 없어 벼는 ‘—’, 고용은 잠금. 정상 테스트는 VillageScene에서 시작한다.
- StartScene은 기본 버튼 배치만 있으며 게임 흐름 연결은 미완성. 빌드 목록은 SampleScene, PlayScene, VillageScene이며 시작 순서는 변경하지 않았다.
- 디스크 저장/불러오기, 전투·이동, 생산·수확, 강화, 해고, 막사에 따른 편성 상한 확장, 시작 건물·병사 자동 지급은 아직 미구현. 실행 종료 시 상태 초기화.
