# 육각 타일 마을 맵과 드래그 카메라 — 2026-09-23

VillageScene의 기존 평면 바닥을 kenney_hexagon-kit FBX 타일 619개로 교체했다. 중앙 건설 평지, 북쪽 산지, 양쪽 숲, 해변과 바다를 배치했다. 원본 에셋은 수정하지 않았다.

- `Village Hex Map/Land Tiles`: 평지·숲·산 타일.
- `Village Hex Map/Coast and Water`: 물 타일.
- `Village Hex Map/Village Paths`: 중앙 흙길.
- 바닥 루트 BoxCollider: 보이지 않는 건설 판정 영역 96×80. 타일 위 평지는 y=0이다.
- `Assets/MapData`: 평지에 사용하는 미세한 색 차이의 머티리얼 3개.

건설 면적은 기존 36×36의 약 5.93배다. 외곽 숲·산·바다는 건설 영역 밖이다. 바닥은 육각 모델이지만 건물 점유는 기존 2단위 사각 그리드를 유지한다. 기존 시작 건물과 저장 위치에 맞게 높이와 그리드 기준의 간격을 유지했다. 저장 파일 형식은 바꾸지 않았다.

맵은 실행 시 생성하지 않고 씬에 편집 가능한 모델 인스턴스로 저장했다. 씬의 타일을 직접 옮기거나 교체할 수 있다. 기존 바닥 루트의 SceneTravel 참조를 유지해서 전장 진입 시 맵 전체가 숨겨지고 마을 복귀 시 복원된다.

## 카메라 조작

왼쪽 마우스를 누르고 드래그하면 땅을 잡아 끄는 방식으로 이동한다. 8픽셀 미만 이동 후 놓으면 짧은 클릭으로 처리해 건물 선택/배치를 한다. 드래그 종료는 클릭으로 처리하지 않는다. UI 위에서 시작한 드래그는 지도 이동으로 사용하지 않는다. 건설 미리보기는 드래그 중 숨긴다.

Village Camera의 `VillageCameraDrag`에서 Drag Threshold와 View Limit을 수정한다. 중심 이동 제한은 X ±75, Z ±55다. 확대/축소는 추가하지 않았다. 앱 포커스 상실과 씬 비활성화 시 드래그 상태를 정리한다.

`BuildingPlacementController`는 Camera Drag 참조가 연결되어 있으면 짧은 클릭의 버튼 해제 시점에 확정한다. 연결하지 않은 씬은 기존 입력을 사용한다. 새 런타임 스크립트는 VillageCameraDrag 하나다.

## 확인

Play 모드의 ProcessPointer 호출로 이동, 클릭과 드래그 구분, UI 시작 드래그 무시, 범위 제한을 확인했다. 확장 영역 (40, 0, -26) 건설 성공, 같은 위치 중복 거부, 바다 쪽 (100, 0, 0) 건설 거부를 확인했다. PlayScene 왕복 시 맵 활성 상태 전환과 콘솔 오류·경고 0개를 확인했다. 물리 마우스 종단 간 테스트는 아니며 기존 저장 파일을 덮어쓰지 않았다. 테스트 건물은 실행 종료로 제거했다.
