# 추가 교범 6개

기존 균등 교육과 합쳐 7개를 PlayScene에 등록했다. 기존 uGUI 카드와 병사 초상화 HUD를 사용한다. 도서관이 있고, 실제 출전 편성이 교범 조건을 만족하면 무작위 후보에 포함된다. 해당 편성만으로 작동하며 기존 레벨업 스킬을 먼저 획득할 필요는 없다.

## 기본 수치

| 교범 | 편성 조건 | 효과 |
|---|---|---|
| 화염 사격 | 궁수 + 마법사 | 마법사 명중 시 4초간 초당 12 피해. 궁수가 점화 대상을 맞히면 반경 3의 적도 점화. 대상별 확산 재사용 1초, 최대 40명 점화. |
| 성벽 돌파 | 방패병 + 기마병 | 전투 시작과 8초마다 살아 있는 기마병에 보호막 40/8초. 방패병 전투불능 시 보급 중단. 돌진 명중 시 최대 40 보호막 소모, 반경 3에 소모량×1.5 피해(기본 최대 60). |
| 교대 선봉 | 병사 + 방패병 | 3초 안에 두 병종이 같은 적을 번갈아 명중시키면 마지막 타격 피해의 60%를 추가 타격으로 적용. 적 방어/약화 판정은 각 타격에 한 번씩 적용. 적별 재발동 0.8초. |
| 추격 명령 | 궁수 + 기마병 | 궁수 명중 시 기존 제압 감속 적용/3초. 기마병이 제압된 적을 돌진으로 처치하면 다음 돌진 피해 +75%, 8초 안에 1회. 화염 발굽 등 지속 피해로는 소모/발동하지 않음. |
| 진형 반격 | 방패병 | 밀집 중 지휘관·병사의 실제 HP 손실과 보호막 흡수량을 최대 200 저장. 산개 전환 시 지휘관 반경 6에 저장량×1.5 피해. 저장량 전부 소모. 방패병이 살아 있어야 축적/반격 가능. |
| 집중 교육 | 병사 1명 이상 | 같은 병사에게 병 3개 연속 투자하면 해당 병사만 공격력 +60%, 공속 +35%, 8초. 다른 병사에게 투자하면 그 병사부터 기록 1. 발동 후 기록 초기화. 새 선봉 발동 시 이전 선봉 강화 종료. |

## 세부 동작

- 일반 공격과 기존 공격 스킬의 명중도 병종 연계로 인정한다. 교범 자체가 가한 추가 피해는 연계를 다시 일으키지 않는다. 모든 교범 피해는 기존 피해·처치·경험치 드롭 경로를 사용한다.
- 화염 피해는 마지막 점화 마법사에게 귀속된다. 불길은 중첩하지 않고 지속 시간만 갱신한다. 점화 대상을 궁수가 처치한 타격도 주변 확산을 일으킨다.
- 성벽 돌파의 교범 보호막은 기존 보호막과 별도 출처로 관리한다. 피해/돌진 소모는 교범 보호막부터 사용하며 부족분은 일반 보호막을 사용한다. 종료 시 해당 교범이 부여한 보호막만 제거한다.
- 진형 반격은 피격으로 소모된 양만 축적한다. 돌진의 자발적 보호막 소모는 축적하지 않는다. 밀집→전개→산개도 저장량을 유지하며 산개 전환 시 소모한다. 같은 진형 버튼을 다시 누르는 것으로 반격하지 않는다.
- 집중 교육의 진행 체크는 현재 연속 투자 대상 초상화에 표시한다. 버프가 끝나도 다음 발동을 위한 투자 기록은 유지한다. 강화 대상이 사망하면 강화는 종료한다.
- 수치형 버프는 기존 버프와 출처를 분리해 다른 스킬을 덮어쓰지 않는다. 종료/비활성화 때 구독과 전투 상태를 정리한다.

## 에디터 설정

`Assets/ManualData`에서 각 교범은 Definition과 Effect 한 쌍이다.

| 교범 | 파일 이름 |
|---|---|
| 화염 사격 | FireVolley / FireVolleyEffect |
| 성벽 돌파 | WallBreak / WallBreakEffect |
| 교대 선봉 | RelayVanguard / RelayVanguardEffect |
| 추격 명령 | Pursuit / PursuitEffect |
| 진형 반격 | FormationCounter / FormationCounterEffect |
| 집중 교육 | FocusedEducation / FocusedEducationEffect |

1. Effect의 `Tactic`은 효과 클래스를 선택한다. `Primary Type / Secondary Type`은 발동에 관여하는 병종이다.
2. Definition의 `Required Types`는 출전 후보 조건이다. 병종을 변경하면 Effect 쪽과 함께 수정한다.
3. 범위·지속 시간·피해·재발동 간격·점화 최대 인원 등은 Effect의 해당 교범 섹션에서 조정한다. 카드 효과 문구는 수치에서 자동 생성한다.
4. `PlayScene > Recruitment System > Relic Draft Controller > Manuals`에 7개 연결 완료. 추가로 연결할 컴포넌트는 없다.
5. 발동 연출은 `CFXR2 Firewall A`, `CFXR2 Ground Hit`, `Healing`을 사용한다. 위치·크기·생존 시간은 Effect에서 조정한다. Healing 연출은 실제 회복을 적용하지 않는다.

새 교범의 아이콘은 기존 도서관 아이콘을 임시로 공유한다. 새 이미지/전용 VFX를 만든 것은 아니다.

## UI와 테스트 키

- 하단 상태 문구는 교범에 따라 점화 인원, 보호막 보급 시간, 교대 횟수, 추격 준비 인원, 반격 축적량, 연속 투자 횟수를 표시한다.
- 발동 시 교범 이름 안내와 짧은 VFX를 표시한다. 공격마다 안내가 화면을 덮지 않도록 발동 안내에 1초 간격을 둔다.
- Editor/Development Build: 편성 화면 **F8**은 도서관 조건만 우회해 교범 선택 화면을 연다. 출전 병종 필터는 유지한다. 전투 중 **F9**는 경험치 병 30개 지급. **Ctrl+1~5**로 투자한다.
- 원하는 교범만 시험하려면 다른 교범의 Unlocked를 잠시 끄거나 Draft의 Manuals 목록을 테스트할 교범만 남기면 된다. 배포 전에 되돌린다.

## 변경 파일

- TacticalManualEffect.cs: 6개 설정 SO, 효과 팩토리, 자동 설명.
- ManualTactics.cs: 교범별 이벤트·상태·타이머·종료 처리.
- CombatController.Manuals.cs: 개별 병사 버프, 안전한 추가 피해·범위 피해·제압, 다음 돌진 1회 보너스.
- CombatController.cs: 명중 이벤트와 실제 돌진 명중 구분. 교범 피해 재발동 차단.
- UnitHealth.cs: 출처별 교범 보호막, 실제 피해/흡수 이벤트. 기존 일반 보호막 유지.
- RunController.cs: 진형이 실제 바뀐 경우에만 전환 이벤트.
- ManualManager.cs / ManualHud.cs: 교범별 상태 문구와 발동 안내. 실행 순서 100으로 병사 HP/경험치 초기화 뒤에 교범을 시작한다.
- PlayScene: 7개 교범 등록.
- Editor/ManualVerification.cs: Preview Scene 기반 검사 메뉴. 사용자 씬과 저장 파일은 변경하지 않는다.

## 검증 상태

- 기존 균등 교육은 이전 Unity MCP 플레이 테스트에서 반복 투자 초기화, 3명 발동, 공격력 1.3배/공속 1.2배, 갱신, 사망 기록 유지, 종료 정리를 확인했다.
- 2026-10-17 추가 교범과 검사 코드는 설치된 Unity 어셈블리를 참조한 로컬 C# 컴파일을 통과했다.
- Unity MCP가 해제되어 새 교범의 실제 플레이/시각 검증은 아직 수행하지 못했다. 배치 실행은 테스트 진입 전에 종료되었으므로 검사 메뉴의 결과를 통과로 간주하지 않는다.
- 에디터에서 Play Mode를 멈춘 후 `Tools > Army Survivor > Verify Manuals` 실행. 에셋 연결·편성 필터, 점화/확산/만료, 보호막 분리/소모/충격파, 교대 판정, 추격 1회 소모, 진형 축적/소모, 집중/균등 투자, 이벤트 해제를 검사한다. 성공 로그는 `MANUAL_VERIFICATION_PASSED`다.

전체 도서관 흐름과 새 효과 작성 방법은 [LibraryManuals.md](LibraryManuals.md)를 참조한다.
