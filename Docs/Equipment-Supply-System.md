# 장비 보급소 · 뽑기 · 3D 관찰 (2026-10-26)

## 플레이 흐름

1. 전투 중 몬스터 처치 시 3% 확률로 Inferno Seal 인장 뽑기권이 떨어진다. 기존 Ticket.prefab의 GUID를 유지하고 자식 모델을 교체했다. 모델 중심을 루트에 맞추고 가장 긴 축을 0.9m로 정규화했다.
2. 지휘관 4m 안에 들어오면 끌려오고, 1.5m 안에서 1장을 획득한다. 전투가 끝날 때 미수거 티켓은 사라지고 수거한 티켓은 유지된다.
3. 마을 건설 목록 또는 왼쪽 `보급소 건설` 버튼으로 왕국 보급소를 건설한다. 최초 비용은 벼 80, 선행 건물 제한 없음. 기존 이동/철거/저장 기능을 사용한다.
4. 보급소가 있으면 왼쪽 `보급소 · 뽑기권 N` 버튼으로 보급 화면을 연다. 1회는 1장, 10회는 10장을 사용한다. 부족하면 버튼이 비활성화된다.
5. 결과 목록 또는 아이템 목록을 클릭하면 3D 모델이 보인다. 드래그로 회전, 휠로 확대/축소, 시점 초기화와 돌아가기 버튼을 제공한다.
6. 출전 준비 화면 왼쪽 `장비 1칸` 버튼에서 지휘관 공용 장비 1개를 장착/해제한다. 미보유 아이템은 관찰만 가능하다.
7. 기존 마을 저장 슬롯을 저장하면 티켓, 중복 수량, 장착 ID, A/S 보장 누적 횟수도 함께 기록된다. 별도 자동 저장은 하지 않는다. 새 게임은 초기화하며, 이전 저장 파일은 장비 없는 상태로 정상 로드된다.

## 초기 아이템과 확률

| 등급 | 아이템 | 보장 제외 기본 확률 |
|---|---|---:|
| C · 2종 | 훈련용 검, 수비대 방패 | 60% |
| B · 2종 | 현자의 지팡이, 왕실의 대검 | 30% |
| A · 3종 | 에테르스톰 블레이드, 화려한 마법 지팡이, 공허의 방패 | 9.4% |
| S · 1종 | 프로스트바이트 단검 | 0.6% |

ZZZ 에이전트 채널의 S 0.6%, A 9.4%, 10회 내 A 이상·90회 내 S 보장을 참고했다. 현재 8종 프로토타입은 C 2종/B 2종/A 3종/S 1종 구성이다. 프로스트바이트 단검을 S급으로 추가하고 S 확률 0.6%와 90회 천장을 다시 활성화했다. 이전에 동결 보존된 S 누적 횟수는 이어서 적용된다. 참고: https://www.icy-veins.com/zenless-zone-zero/exclusive-channel

이번 구현은 기본 확률과 하드 천장을 사용하는 간소화된 장비 풀이다. ZZZ의 소프트 천장, 픽업/반천장, 통합 확률 1.6%를 복제한 시스템은 아니다. 보장이 발동하는 회차의 실제 확률은 기본 확률과 다르다.

- A 이상이 나오면 A 누적 횟수 초기화, S가 나오면 S 누적 횟수도 초기화한다.
- 단뽑 누적과 10회 뽑기는 같은 카운터와 같은 추첨 로직을 사용한다.
- 등급 안에서는 등록된 아이템이 균등 확률로 나온다. C 각 30%, B 각 15%, A 각 약 3.1333%, S 0.6%이다(보장 제외).
- 기존 4종의 ID를 유지했으므로 이미 보유/장착한 장비의 기록은 유지되고 표시 등급만 변경된다.
- 중복은 보유 수량만 누적한다. 분해/판매/강화는 미구현이다.
- **아이템 스탯 효과 및 지휘관 외형 변경, 뽑기 연출은 이번 범위에 포함하지 않는다.**

## 조정 위치

- `Assets/Resources/EquipmentCatalog.asset`: 드롭 확률, 획득·흡인 거리/속도, 티켓 프리팹, 등급 확률, A/S 보장 횟수, 아이템 목록, 글꼴, 보급소 정의.
- `Assets/EquipmentData/*.asset`: 아이템 ID/이름/등급/설명/3D 모델/미리보기 기본 회전.
- `Assets/EquipmentData/SupplyDepot.asset`: 건설 비용/건물 모델/점유 면적.
- `Assets/EquipmentData/Ticket.prefab`: Inferno Seal 인장 뽑기권. 자식 `Inferno Seal Visual`의 Scale로 크기를 조절할 수 있다. 원본 모델은 `Assets/Art/Meshy/Props/InfernoSeal`에 있다.
- `Assets/EquipmentData/InfernoSealIcon.png`: 실제 인장 모델을 정면 렌더한 256×256 투명 Sprite. 카탈로그의 `ticketIcon`으로 연결하며 상단 보유량과 1회/10회 보급 비용에 공통 사용한다. 아이콘은 클릭을 가로채지 않는다.
- 아이콘 재생성: Edit Mode의 `Army Survivor > Equipment > Bake Ticket Icon`. 게임 중에는 추가 카메라 렌더링 없이 저장된 Sprite를 사용한다.

기본 연결은 완료했다. 직접 레이어나 카메라, UI 프리팹을 연결할 필요가 없다. `ItemInspect` 전용 레이어는 31번이며, 런타임은 이를 이름으로 조회한다. UI는 기존과 같은 uGUI + TMP이고 씬 진입 시 생성된다. 관찰 카메라는 아이템 선택/회전/줌 때만 렌더링하고 닫으면 RenderTexture와 모델을 해제한다. 프리뷰는 전용 레이어와 먼 위치로 격리한다.

재설치가 필요하면 Edit Mode에서 `Army Survivor > Equipment > Install Supply and Equipment` 메뉴를 실행한다. 보급소 정의를 Village/StartScene의 저장 카탈로그와 건설 목록에 등록한다. 이미 등록된 것은 중복 추가하지 않는다.

새 아이템: `Create > Army Survivor > Equipment > Item`으로 생성 → 고유하고 변하지 않는 ID 입력 → 모델/등급/설명 지정 → EquipmentCatalog의 Items 배열에 추가. 저장에 사용한 기존 ID를 변경하면 해당 아이템 복원이 끊기므로 유지한다.

테스트용 티켓: Play Mode에서 `Equipment System`의 EquipmentRuntime 컴포넌트 메뉴 → `Testing/Grant 10 Tickets (Play Mode)`. 에디터에서만 노출되며 저장하지 않으면 테스트 지급은 영구 저장되지 않는다.

## 수정 파일 및 검증

- 신규 `Assets/Scripts/Equipment/`: 아이템/카탈로그 SO, 인벤토리 및 추첨, 전투 드롭 연결, uGUI 화면, 3D 관찰, 설치 도구.
- `GameSave.cs`: 기존 슬롯에 equipment 필드 저장/복원, 새 게임 초기화만 추가. 기존 전투/스탯 로직은 변경하지 않음.
- VillageScene: 보급소 건설 선택지 및 저장 정의 추가.
- StartScene: 보급소 저장 정의 추가(메인 화면의 불러오기 검증에 필요).
- TagManager: ItemInspect 레이어 추가.

검증: Unity 컴파일, 부족 티켓 차감 방지, 미보유 장착 방지, 동일 난수 시드에서 단뽑 10회와 10회 뽑기 일치, A/S 보장, JSON 장비 저장 왕복, 실제 보급소 건설/10회 보급/모델 표시/드래그·줌 핸들러, 준비 장착, 전투 처치 이벤트 티켓 생성과 지휘관 획득을 확인했다. 테스트 건물/티켓은 Play Mode 종료로 폐기했다.

MCP 스크린샷 도구에서 PlayerLoop 재귀 오류가 발생했으며 스택은 MCP 패키지의 ScreenshotUtility를 가리켰다. 화면 캡처 호출을 제외한 전투/장비 검사에서는 오류가 없었다.
