# 뽑기 테스트 환경

Unity 메뉴 **Army Survivor > Equipment > Open Draw Test Window**를 연다.

1. Edit Mode에서 **VillageScene에서 테스트 시작**을 누른다. 수정 중인 씬은 Unity의 저장 확인 창을 거친다.
2. VillageScene이 Play Mode로 시작되면 자동으로 테스트 모드와 보급 화면이 열린다. 보급소 건설은 필요 없다.
3. 기본은 테스트 인장 1,000개와 무제한 인장이다. 실제 게임 화면의 1회/10회 보급 버튼 또는 테스트 창의 버튼을 사용한다.
4. Game 창에서 ESC로 연출을 건너뛸 수 있다.
5. **테스트 종료 · 이전 장비 상태 복구** 또는 Play Mode 종료로 끝낸다.

## 확인 버튼
- **A급 이상 보장 직전**: 다음 뽑기가 A 이상인 상태. S도 정상 결과다.
- **S급 보장 직전**: 다음 뽑기가 S인 상태.
- **인장 0개 · 부족 상태 확인**: 무제한 모드를 끄고 인장을 0으로 설정. 게임 화면의 보급 버튼 비활성화 확인.
- **인장 1,000개 · 보장 카운터 초기화**: 기본 확률부터 다시 테스트. 보유 장비는 유지.
- **보급 UI 다시 열기**: 닫힌 보급 화면을 다시 연다.

연출 중에는 테스트 창의 변경/뽑기 버튼을 잠근다. 원래 확률, 카탈로그와 보장 수치는 변경하지 않는다. 무제한은 부족한 인장을 채워주는 방식이며 기존 추첨 코드를 그대로 실행한다.

## 저장과 범위
테스트 시작 시 기존 장비 상태를 메모리에 보관한다. 테스트 중 EquipmentInventory.Capture는 테스트 전 장비 상태를 반환하므로 테스트 인장·장비가 저장되지 않는다. 테스트 종료 시 원래 상태를 복구한다. 저장 파일 불러오기/새 게임은 테스트 모드를 해제한다.
이 보호는 **장비 데이터만** 대상으로 한다. 테스트 중 마을 건설 등 다른 데이터를 변경하고 직접 저장하면 해당 변경은 저장될 수 있다.
테스트 창을 닫는 것만으로 테스트가 종료되지는 않는다. 다시 창을 열어 종료하거나 Play Mode를 종료한다.
테스트 API와 건물 조건 우회는 UNITY_EDITOR 조건부 컴파일로 일반 빌드에 포함되지 않는다.

## 검증
Unity의 기존 컴파일 응답 파일과 Roslyn 컴파일러로 런타임/에디터 어셈블리 컴파일 통과. 실제 Play Mode UI 조작과 연출은 이번 작업에서 실행하지 않았다.
