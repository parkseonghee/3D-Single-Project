# 지휘관 성장 · 지원형 카드 (2026-10-19)

## 성장 규칙

- 필드의 경험치 병 수집: 보유 병 +1, 지휘관 경험치 +10. 병사의 기존 Ctrl+숫자 투자 방식 유지.
- 카드/디버그로 직접 지급한 병은 지휘관 경험치를 올리지 않는다. 병사에게 투자할 때도 지휘관 경험치를 중복 지급하지 않는다.
- Lv.1부터 시작. 다음 레벨 필요 경험치는 50, 80, 110, 140…으로 30씩 증가. 초과분 이월, 여러 레벨 상승 시 선택도 순서대로 처리.
- 지휘관 레벨업마다 중복 없는 지원 카드 최대 3장 중 1장 선택. 기존 병사 강화/즉시 보상 선택 중에는 대기하며 선택창이 겹치지 않는다.
- 선택 중 전투 정지, 선택 후 이전 시간 배율 복귀. 선택 가능한 카드가 모두 최대 단계라면 선택을 생략한다.
- 전투 종료 시 레벨, 경험치, 지원 카드, 부활 예약과 버프 초기화.

## 지원 카드

| 카드 | 단계당 효과 | 최대 단계 |
|---|---|---:|
| 보급 회수 | 경험치 병 획득 반경 +40% | 3 |
| 야전 교육 | 병사에게 투자하는 병 경험치 +20% (100 → 120/140/160) | 3 |
| 긴급 후퇴 | 지휘관이 체력 30% 이하 상태에서 피격되면 전 부대 이동속도 +50%/단계, 5초 지속, 재사용 30초 | 3 |
| 예비 병력 | 획득 후 처음 사망한 병사 1명을 5초 후 진형 위치에서 체력 50%로 부활 | 1 |
| 정예 사냥 | 중간 보스·최종 보스에게 주는 피해 +20% | 3 |
| 전리품 계약 | 모험 전투 승리 보상 골드 +50 | 3 |

같은 카드 단계 보너스는 가산한다. 긴급 후퇴는 다른 이름의 이동속도 버프와 곱해지고 피해를 받아야 발동한다. 예비 병력은 지휘관을 부활시키지 않으며 획득 이전 사망자에게 소급 적용하지 않는다. 부활은 기존 레벨·스킬·최대 체력을 보존한다. 전리품 계약은 보상 화면과 실제 마을 지급량에 함께 반영되며 패배/중도 복귀에는 지급하지 않는다. 승리 보상이 없는 생존 모드의 추첨에서는 제외한다.

## UI / 에디터 설정

PlayScene의 Recruitment System에 CommanderProgression과 한글 폰트 연결 완료. 추가 연결 불필요.

- Inspector의 CommanderProgression: 경험치 수치, 획득 반경/투자/보스 피해 증가량, 추가 골드, 후퇴 조건/지속/재사용, 부활 지연/체력 비율 조절.
- 기존 uGUI/TMP 사용. 화면 상단 중앙에 지휘관 Lv./EXP 바, 지원 획득/발동 메시지 표시. 선택 화면은 런타임 생성.
- 카드별 그림 에셋은 아직 없으므로 이름/단계/효과를 표시하는 기존 스타일의 텍스트 카드로 제공.
- 디버그 병 지급은 경험치 수집과 구분하므로 F9 병 지급으로 지휘관이 레벨업하지 않는다.
