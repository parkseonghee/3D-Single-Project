# 서바이벌 모드 시작 규칙

서바이벌은 모험 Day 5에 도달하면 해금된다. 시작 화면에서 서바이벌을 누르면 마을을 거치지 않고 전투 씬으로 이동한다. 매 도전마다 출전 병사 다섯 명을 병종 후보에서 무작위로 뽑는다(같은 병종 중복 가능). 전투 직전에 교범 한 장을 고르고, 이어서 무작위로 제시되는 생존 계약 세 장 중 한 장을 고른다. 두 선택을 마치면 곧바로 전투가 시작된다. 재도전하면 병사와 계약을 다시 뽑는다.

서바이벌에서 인장을 주우면 보급권을 쌓는 대신 기존 장비 확률표에 따라 무기 한 개를 무작위로 얻고 즉시 장착한다. 이때 전투를 멈추고 실제 3D 무기를 회전·확대해 볼 수 있는 획득 화면을 띄운다. `전투 계속` 또는 Esc로 닫으면 전투가 재개된다. 방패는 추첨 대상에서 제외한다. 등급에 따라 기본 공격 피해 보너스는 C +10%, B +20%, A +35%, S +60%다. 중복 무기도 추첨될 수 있다. 모험 모드의 마을·고용·인장 보급 흐름은 유지한다.

## 생존 계약 후보

매 도전에서 아래 12개 중 3개가 중복 없이 제시된다. 수치는 기본값 대비 배율이며 `Assets/Resources/SurvivalSettings.asset`의 `Opening Tradeoffs`에서 조정한다. **공격력·공격 속도는 병사의 기본 공격**, 이동 속도는 지휘관과 부대 이동, 체력은 최대 체력에 적용한다. 몬스터 등장 간격 감소는 더 많은 적이 나온다는 뜻이다.

| 선택지 | 보상 | 위험 |
|---|---|---|
| 유리 대포 | 병사 공격력 +65% | 지휘관 최대 체력 -40% |
| 철갑 행군 | 병사 최대 체력 +50% | 부대 이동 속도 -25% |
| 광전사 | 병사 공격 속도 +50% | 지휘관 최대 체력 -30% |
| 질주 | 이동 속도 +35% | 병사 최대 체력 -25% |
| 가혹한 훈련 | 경험치 획득량 +50% | 병사 최대 체력 -20% |
| 전리품 사냥 | 경험치 병 획득 반경 +60% | 병사 공격력 -20% |
| 포위 유도 | 병사 공격력 +40% | 일반 몬스터 등장 간격 -25% |
| 느린 방진 | 지휘관 최대 체력 +45% | 병사 공격 속도 -30% |
| 최후의 맹세 | 경험치 획득량 +80% | 지휘관 최대 체력 -50% |
| 돌격 진형 | 이동·공격 속도 +25% | 병사 최대 체력 -40% |
| 중갑 방진 | 병사 최대 체력 +60% | 병사 공격 속도 -30% |
| 전쟁 열병 | 병사 공격력 +30%, 경험치 +25% | 일반 몬스터 등장 간격 -30% |

### 밸런스 확인 지점

처음 10분 동안 위험을 감수한 선택이 체감되도록 공격형, 성장형, 생존형을 섞었다. 특히 `최후의 맹세`와 `유리 대포`는 한두 번의 피격으로 끝날 수 있으므로 실제 플레이에서 생존 시간과 선택률을 보고 수치를 조정한다. `포위 유도`와 `전쟁 열병`은 스폰 상한에 도달하면 위험이 덜해질 수 있으므로 적 밀도를 함께 확인한다.
